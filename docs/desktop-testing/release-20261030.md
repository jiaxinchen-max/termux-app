## 包内容

- KWin r27 提供 9 个原生 deb。完整 r26 KWin 包中替换 8 项已验载荷，另将已验 Qt popup 插件纳入完整 QtBase 包；其 GTK、cross-tools 等值依赖同步版本。其余载荷、维护脚本和冲突声明保留，md5sums 与安装大小重新生成。两次重打包 SHA 完全一致。

- 两份 release 均附源码或构建输入、重打包脚本及 SHA 清单。设备日志、数据库、缓存和截图未上传。
- KWin release 另附 4 个 `6.7.4-3+termuxfix4` Discover deb，只用于 Debian forky 容器，不能安装到 Termux host。App 当前不会自动给新容器安装这些定制包；安装及验证方法见附件说明和 [fix4 记录](discover-packagekit-refresh-20261030.md)。

## App pins 与验证

`DesktopLaunchSpec` / `desktop_install.sh` 切换 KWin r27；`XServerTasks` / `x-server-packages.txt` 及桌面安装脚本切换 Xserver r7。包名及 SHA 与 release 精确匹配，KWin 安装清单显式包含完整 9 包。

指定编译机完成全套桌面脚本契约、467 项 UI 单测、105 项 X11 单测及 APK 构建，零失败、错误或跳过。发布 pins APK SHA256 为 `fc6aaaa2f5de39cc25563f4421e64a2a134dea131091b3ec76e689dc391e34cd`。

与已验 v6 比较，仅两项安装 assets、DEX 中两处 release 常量及对应校验/签名元数据变化；5 个 native 库、其余 16 个 DEX 和 session 脚本保持逐字节一致。正式 App UI 验收是 [v6 记录](validation-20261030.md)，不将 pins 构建或 deb 重打包检查写成新的设备 UI 安装验收。

App 提交排除 7 个原有 dirty cpp 子模块和重复生成的旧验证记录。旧 APK 固定旧 release URL；旧 release 删除后，需要使用本次更新的 App 代码构建版本才能重新下载组件。
