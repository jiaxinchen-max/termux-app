# Wine 独立配置 C 盘备份与恢复（2026-11-03）

Proot 应用配置的卡片菜单及快捷面板新增 C 盘备份入口，提供备份与恢复。Storage 保持只读统计；核心组件设置中的共享基础环境备份不变。Native 菜单不提供 C 盘备份，任务 API 也拒绝 Native 和共享容器。

归档为 `.wine-cdrive.zip`，仅包含 `drive_c/`、`system.reg`、`user.reg`、`userdef.reg` 和格式说明。C 盘中的符号链接保存链接本身，不跟随到外部目录。前端运行配置、挂载映射、共享 RootFS、运行组件、前缀模板和外部应用目录不进入归档；存放在 C 盘内的应用程序、用户数据及设置文件会随 C 盘一起备份。恢复要求当前选择的 Wine 组件与归档一致。

恢复先在同一私有文件系统的临时目录中解压并验证范围、CRC 和大小，复制当前前缀的盘符映射及就绪元数据后替换目标前缀。原 C 盘的替换和清理由任务日志记录提交阶段；中断任务只执行清理并报告失败，不重放操作。缺失注册表可以从有效备份恢复。

备份直接在共享存储独占创建目标文件，记录设备号和 inode，完成 ZIP 关闭及同步后记为成功。初次 UI 验证发现模拟器共享存储不支持 `renameat2(RENAME_NOREPLACE)`（EINVAL），因此备份输出统一采用独占创建设计；没有运行时切换输出方案。失败清理需要文件身份与本任务记录一致，既有文件不会被覆盖。

归档期间禁止启动应用、准备环境、删除配置和修改运行配置。前台服务持有 I/O，会话框使用准备日志显示进度；关闭窗口不会结束任务。
