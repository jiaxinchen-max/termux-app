# UI 主题设置

设置首页新增“UI theme / 界面主题”：Auto（跟随系统）、Light（固定浅色）、Dark（固定深色）。选择立即应用并保存于 `local_games_settings.ui_theme`。

每个 UI Activity 使用本地 AppCompat 夜间模式；创建视图前应用，保留页面再次显示时同步最新选择。Wine / Desktop 会话的菜单也使用此选择，继续保留各自的屏幕方向。UI 终端复用同一选择，并以 Activity 的实际配色渲染会话列表。终端文本和扩展按键沿用终端自身颜色。

公共导航统一设置系统栏背景和图标，清除 UI 终端原透明系统栏标志，使用现有浅色、深色资源。API 27 以下保持深色系统栏及浅色图标。主题从 Light 改为同色的 Auto 时也立即刷新设置摘要。

桌面创建与设置页移除固定浅色值：选中卡片使用独立日夜背景，分组标题、下拉箭头和勾选标记使用对应主题的颜色。选中卡片的主次文字均检查实际截图中的文字颜色和背景对比度，避免只检查页面底色而漏掉局部不可读状态。

## 验证

- 本地构建 APK；`UiThemePreferenceTest` 3 项通过，验证三种模式映射、保存值与非法值拒绝。
- Pixel_7_API_35（emulator-5554）从正式设置页面选择主题，截图与像素检查固定主题、系统联动、重复使用的页面和 UI 终端导航 / 系统栏。
- Light 在系统深色时保持浅色，Dark 在系统浅色时保持深色；Auto 随系统变化。
- 检查 Wine、Desktop、Files、Terminal、Settings，以及帮助弹窗、桌面创建页面和横屏显示。
- 桌面选中卡片实际截图：深色主文字 / 说明对比度 11.51 / 5.66，浅色为 13.37 / 4.71，均达到 4.5；文字像素与主题色一致。
- 测试后恢复 Auto，并恢复模拟器原系统深浅色和旋转设置；不启动游戏或桌面安装任务。
