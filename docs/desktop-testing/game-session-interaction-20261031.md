# 游戏会话抽屉：方向与触控（2026-10-31）

## 行为

- 游戏运行界面的“操作”抽屉增加触控模式和屏幕方向菜单，保留原有手柄入口。
- 触控模式：跟随 X11、触控板、模拟触屏、直接触控；运行时值分别为默认值、`1`、`2`、`3`。
- 方向仅有横屏、竖屏、自动，不提供“跟随 X11”。未保存方向的游戏默认横屏；不读取应用或 X11 全局方向。方向只控制窗口，游戏仍使用配置的渲染分辨率。
- 使用 `game:<gameId>` 键保存每个游戏的选择，不读写全局方向或桌面方向覆盖。退出后再次启动仍使用该游戏的选择。
- 复用桌面覆盖存储，将类名统一为 `X11SessionOverrides`；保留原 SharedPreferences 文件及桌面键，导入导出格式不变。
- 游戏和桌面会话在暂停时归还共享触控值，恢复时应用自己的覆盖；销毁已暂停的会话不会清除其他会话的恢复记录。
