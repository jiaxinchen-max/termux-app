# 创建页紧凑卡片

## MODIFIED Requirements

### Requirement: 卡片高度由外观尺寸及字体决定
Native 和 PRoot 新建页的四类选项 MUST 使用紧凑横幅，普通字体高度为 52dp。字体变大时 MAY 按字体倍率增高；视口高度改变 MUST NOT 使装饰背景把卡片拉成整屏高。列数及宽度 MUST 沿用按实际可用宽度自适应的规则。

#### Scenario: 有限的横竖屏视口
- **WHEN** 用户在不同宽度及高度的窗口打开任一模式的新建页
- **THEN** 相同字体下卡片高度稳定，四类型顺序及选中状态保留，后续参数和创建按钮可通过正常滚动到达。

#### Scenario: 大字体和窄窗口
- **WHEN** 用户放大字体或收窄窗口
- **THEN** 允许卡片按字体有界增高并减少列数，名称区域与勾选/已创建区域不遮挡；长文字可按现有方式换行、缩放或省略，完整名称保留在文本和无障碍说明中。

### Requirement: 修复布局不改变创建语义
系统 MUST 保留每类 Native 仅一个实例及已创建提示、PRoot 可重复创建、渲染选择、名称编辑、页面恢复和创建后自动安装。已删除的更多菜单 Install MUST NOT 因本次修复恢复。

#### Scenario: 选择、创建和返回列表
- **WHEN** 用户选择可用类型并完成创建
- **THEN** 保存内容和后续安装仍沿用当前流程，桌面管理页保持已有固定尺寸和菜单行为。
