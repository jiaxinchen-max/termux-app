# 修复新建桌面选项卡片被拉长

## 用户确认的缺陷
用户在前次管理页修复后提供 Native 新建页截图，指出新建是否遗漏修复。截图确认四种桌面选项被纵向拉成整屏高，把后续表单挤出视口。本轮按该缺陷反馈补齐新建页；不会把此前只改管理页的交付描述为已覆盖新建页。

## 目标与范围
Native 与 PRoot 共用的新建页选项必须保持紧凑横幅高度：普通字体为现有封面高度 52dp，大字体按字体倍率有界增长，不依赖视口的剩余高度。列数和宽度继续按现有规则适应窗口。名称与勾选/已创建提示保持各自区域，后续参数和创建按钮可正常滚动访问。

## 非目标与兼容性
只修正卡片的布局测量及文字容纳，不改变桌面类型、Native 唯一性、PRoot 重复实例、选择/保存/自动安装或安装状态机。保留此前菜单删除和 Hyprland 等全部未提交修改。旧规格允许创建页随字体增高，本次保留该能力，只约束背景不再把卡片扩至视口高度。

## 风险、验证与回滚
主要风险为大字体或窄屏下文字裁切，使用真实 Android 布局测量覆盖两模式、宽窄屏、有限视口、浅深色和两档字体；先记录旧实现失败，再验证补丁。运行已有创建/管理页回归和 arm64 APK 构建。回滚仅恢复本次布局、摆放参数和测试。无设备时记录界面最终验收 Pending。
