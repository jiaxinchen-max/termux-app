# Native默认Box64 0.2.8

## 修改需求：默认版本
Native默认Box64必须为glibc_box64_0.2.8，组件列表不再提供0.2.7。0.3.8和0.4.4仍可独立安装和按游戏选择，PRoot默认0.4.5及0.3.8候选不变。

### 场景：默认安装与启动
未显式选择Box64的Native游戏必须安装并运行0.2.8独立组件目录中的程序，配套库来自该组件的lib/x86_64-linux-gnu。

### 场景：缺少组件
缺少0.2.8程序时应失败，不得执行旧版、全局程序或其他候选。

### 场景：版本隔离
显式选择0.3.8或0.4.4必须继续使用该版本目录；卸载或重装一个版本不得修改另一个版本。

## 新增需求：真实构建与交付
0.2.8资产必须来源于固定上游提交，使用Native glibc加载路径并包含x86_64支持库。APK名称保持termux-app_apt-android-7-debug_arm64-v8a.apk且testOnly=false，用户手动安装和验证游戏。
