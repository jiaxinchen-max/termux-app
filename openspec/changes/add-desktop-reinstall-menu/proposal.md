# 添加桌面重新安装菜单

用户明确要求“添加重新安装菜单执行重新安装”，本轮以该具体实施请求为授权，补齐 Native 和 PRoot 桌面菜单。沿用已有确认与安装控制台，菜单名称明确为“重新安装”，不恢复此前含糊的 Install。

所有受支持桌面统一显示菜单，不依赖已安装/未安装/失败状态；有桌面会话时保持可操作，确认后先杀死受影响桌面进程并确认退出，再执行重装；停止失败不得安装。共享宿主组件涉及所有受管理桌面，需先保护活动安装并停止相关会话；归档忙碌仍受操作锁保护。用户确认后重新安装受管理桌面软件包及 Hyprland 合成器，重新准备会话。保留原桌面 ID、设置、容器和用户文件，不删除或重新创建容器；验证通过的下载缓存、主题资源和 EWW 可复用。失败传播到现有安装任务结果，不伪造成功。

HTTP 合约不变，api_docs 为 N/A。docs/product/desktops.md 为计划产品知识入口，product_docs Required、一致性 Pending，最终用户验收前不固化正式产品知识。保留 Native 四个固定入口及布局修复，APK 保持原名 termux-app_apt-android-7-debug_arm64-v8a.apk。
