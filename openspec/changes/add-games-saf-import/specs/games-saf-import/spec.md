## ADDED Requirements

### Requirement: 用户通过 SAF 导入已安装游戏目录

系统 MUST 使用 Android SAF 目录选择器并持久化读权限，不得要求全盘存储权限或复制游戏本体。

#### Scenario: 选择可访问目录

- **WHEN** 用户选择游戏目录并授予持久读权限
- **THEN** 系统在后台扫描目录
- **AND** Game 记录保存 tree URI 和相对路径
- **AND** 用户原始目录不被修改

#### Scenario: 持久权限失效

- **WHEN** 待导入 tree URI 不再具有持久读权限
- **THEN** 系统阻止确认导入
- **AND** 显示重新选择目录的动作

### Requirement: 目录扫描有确定上限

系统 MUST 限制扫描深度、文档数、目录数、候选数和声明总大小，并报告命中的限制。

#### Scenario: 超大或异常目录

- **WHEN** 扫描达到任一配置上限
- **THEN** 系统停止相应遍历或整个扫描
- **AND** 已发现候选仍可供用户确认
- **AND** 页面明确标记结果可能不完整

### Requirement: EXE 候选经过校验并可手动纠正

系统 MUST 仅接受扩展名为 `.exe` 且具有有效 DOS/PE 签名的文件，并按可解释规则稳定排序。

#### Scenario: 目录包含多个可执行文件

- **WHEN** 扫描发现主程序、启动器、卸载器和崩溃报告器
- **THEN** 页面展示排序后的候选及识别依据
- **AND** 卸载器、安装器、崩溃报告器和再发行组件被降权并标记
- **AND** 用户可以选择任一通过 PE 校验的候选

### Requirement: 确认导入原子保存 Game

系统 MUST 让用户确认名称、主程序、相对工作目录和启动参数，并在私有存储中原子保存。

#### Scenario: 持久化失败

- **WHEN** Game 写入或替换失败
- **THEN** 页面保留当前候选和输入
- **AND** 不显示导入成功
