## MODIFIED Requirements

### Requirement: PRoot 导出文件名可识别来源容器
系统 MUST 为所有支持导出的 PRoot 桌面生成“安全容器名称-ID-时间.desktop.tar.gz”文件名。名称取导出时选中的容器显示名称；保留原有固定目录、重名保护、存档后缀和兼容性。

#### Scenario: 导出中文名称容器
- **WHEN** 用户导出已停止、满足原有条件且名称为“工作桌面”的 PRoot 容器
- **THEN** 导出文件名以“工作桌面-”开头，随后包含原容器 ID 和时间，后缀为 .desktop.tar.gz。

#### Scenario: 容器名称有特殊字符或过长
- **WHEN** 名称含路径分隔符、文件系统非法字符、控制字符、前导点或过长 Unicode 文本
- **THEN** 名称片段安全替换并按码点限制为至多 80 个 UTF-8 字节，文件仍位于既有备份目录；存档元数据保留完整容器原名。

#### Scenario: 兼容恢复与重复导出
- **WHEN** 用户重复导出或恢复新旧名称格式的存档
- **THEN** 重名保护、文件后缀识别、完整性校验及恢复名称规则保持原有行为。
