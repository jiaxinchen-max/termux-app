# Wine 前缀模板规范

## Purpose

将 Wine 前缀模板作为按需生成、可校验和可再生的缓存，避免未使用运行库带来的磁盘与初始化成本，同时保持不同 Wine、翻译器和游戏前缀的兼容隔离以及损坏现场保护。

## ADDED Requirements

### Requirement: 模板只为实际选择按需生成

系统 MUST 在显式配置准备任务首次需要时生成对应 Wine 模板，随后复用匹配模板；基础环境构建或恢复 MUST NOT 无条件为所有目录中的运行库预热模板。

#### Scenario: 首次准备 Hangover 配置

- **WHEN** 用户首次准备 Hangover 游戏且没有匹配模板
- **THEN** 准备任务生成并发布 Hangover 对应模板，再初始化该游戏前缀
- **AND** 不生成 Wine 10 或 Proton 11 的模板

#### Scenario: 后续同版本配置

- **WHEN** 另一个配置需要相同完整模板身份且缓存校验通过
- **THEN** 克隆已有模板到该配置独立前缀，不重新执行全量模板初始化

### Requirement: 模板身份包含所有兼容性输入

模板身份 MUST 区分 Wine 制品版本和摘要、实际翻译器身份、架构、基础环境兼容配方与初始化修订；MUST NOT 只以显示名称、组件 ID 或翻译器家族复用模板。

#### Scenario: 同名组件字节或翻译器发生变化

- **WHEN** Wine 组件摘要、所选翻译器版本或初始化配方变化
- **THEN** 原模板不被作为新身份模板复用
- **AND** 原配置仍能继续引用其原运行库与模板身份

#### Scenario: 各 Wine 家族之间切换选择

- **WHEN** 用户为新配置选择 Wine 10、Proton 11 或 Hangover
- **THEN** 只使用该选择完整匹配的模板
- **AND** 不共享其他 Wine 的可写 C 盘或将不匹配模板静默更新后当作匹配

### Requirement: 模板构建并发排他且原子发布

同一模板身份 MUST 只有一个构建者，其他需求 MUST 复用或等待持久结果；构建必须在私有暂存中完成并校验后原子发布，取消、超时或崩溃不得产生可复用的半成品。

#### Scenario: 两个配置同时需要同一新模板

- **WHEN** 两个准备请求并发到达
- **THEN** 仅一个请求执行模板 wineboot，其余请求在明确状态下等待或复用完成结果
- **AND** 每个请求最终只初始化自己的前缀

#### Scenario: 模板构建中止

- **WHEN** 构建者取消、失败或进程被终止
- **THEN** 已有有效模板保留，临时目录不标记为成功
- **AND** 后续准备能够识别中断、恢复或重新构建，不遗留无限等待

### Requirement: 模板损坏与游戏前缀损坏分别处理

系统 MUST 在使用模板前检查身份和完整性；无效缓存只允许在准备任务中重建。已有非空且损坏或身份不匹配的游戏前缀 MUST 保留现场并明确报错，MUST NOT 被模板覆盖。

#### Scenario: 缓存归档损坏

- **WHEN** 模板归档被截断或摘要不匹配
- **THEN** 准备任务拒绝复用并显式重建该缓存
- **AND** 不修改其他模板与已有游戏前缀

#### Scenario: 已有游戏 C 盘损坏

- **WHEN** 准备发现非空游戏 C 盘不具备有效运行标记
- **THEN** 提示用户显式恢复或重建该 C 盘
- **AND** 不删除目录、不展开模板、不在普通启动中修复

### Requirement: 模板清理保持引用和运行隔离

模板缓存 MUST 可在显式清理中按身份回收无引用条目；活动构建、准备、新布局恢复引用的条目 MUST 保留。清理不得删除游戏前缀、运行库、存档或外部文件。

#### Scenario: 清理未使用的模板

- **WHEN** 用户执行模板清理且某模板未被配置、活动任务或事务引用
- **THEN** 只删除该模板缓存及安全暂存
- **AND** 后续有新需求时通过准备任务重新生成

### Requirement: 准备阶段承接首次成本且正常启动仅消费

首次模板构建 MUST 显示可跟踪的初始化进度与取消结果；正常启动 MUST 仅使用已准备前缀和依赖，不触发模板构建、隐式 wineboot 或无关组件下载。

#### Scenario: 模板准备尚未完成就启动

- **WHEN** 用户尝试启动尚未完成准备的配置
- **THEN** 显示准备中或准备失败的可恢复状态
- **AND** 不启动第二套隐式初始化，也不改用另一运行库
