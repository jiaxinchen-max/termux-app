# Native 桌面运行时依赖

## 新增需求：定制 Qt 的 ICU ABI 匹配

系统必须为当前 Native 桌面提供与目标 ICU ABI 匹配的定制 Qt；包管理器的最低版本依赖不能代替 ELF 动态依赖检查。

### 场景：ICU 79 环境

- 当目标环境安装 ICU 79 时，候选 Qt 必须链接真实的 ICU 79 共享库。
- 候选包依赖必须排除未验证兼容的下一主版本。
- 必须保留已有定制补丁及显式渲染规则，不允许通过创建跨 ABI 库名链接或失败回退掩盖不匹配。

### 场景：候选验证与发布

- 静态依赖检查通过只代表二进制依赖检查完成，不代表用户界面验收通过。
- 公开资产更新、App 清单接入和设备安装必须遵守各自授权范围。
