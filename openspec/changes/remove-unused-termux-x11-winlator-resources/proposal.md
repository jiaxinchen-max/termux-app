# 清理 termux-x11 闲置代码与资源

## 目标与范围

用户要求清理 termux-x11 未使用的代码与资源，重点检查 Winlator 遗留内容。本变更只删除当前应用没有使用的实现，保持程序运行、控制器和 XServer 的现有行为。

已完成 Java 编译引用、跨模块源码、Android 资源依赖、动态资源名、JNI、清单及各 ABI 原生构建清单核对。具体文件与资源定义以本目录 `cleanup-manifest.json` 为准：计划删除 104 个文件，修改 11 个文件，其中 8 个只删除闲置资源定义。

- 删除旧容器、快捷方式及其专属工具链共 10 个 Java 类，并移除仍在活动控制器中但结果无人使用的旧模型初始化。
- 删除 24 个旧布局、6 个菜单、51 个图像资源，清理配套文案、数组与样式，共 260 个资源符号，覆盖默认、中文及夜间变体。
- 删除无人调用的 start-tfm 和 wfm.exe，以及未接入构建且没有 Java 宿主的 11 个 xrio 文件。
- 仅删除 controller_runtime.sh 中提及 start-tfm 的历史注释，脚本执行内容保持不变。

## 用户可见行为与边界

安装后的页面、程序启动、控制器配置、XInput/DirectInput、任务管理及图形渲染必须保持现状。保留 wine-bridge.exe、全部架构的控制器 DLL 包 wine.tar.gz、动态枚举的按键图标和配置模板、当前使用的 Winlator 来源输入代码，以及 Vortek 中参与编译的代码。保留许可证、第三方子模块、权限和清单声明。

本次不升级依赖版本，不修改运行时组件、资源下载、数据布局、迁移和兼容策略。现有 PRoot 裁剪与构建失败修复的未提交修改不属于本次范围。不包含 Git 提交、推送、发布或设备操作。

## 预期收益、风险与回滚

删除文件合计源文件大小 582,056 字节，尚未计入共享 XML 文件中移除的定义。此数不是 APK 缩减量。两份旧资产在当前 APK 中合计压缩大小为 72,986 字节；源码、资源合并及 DEX 的最终变化需构建后测量。

主要风险是动态引用或资源 ID 定义被误删。设计要求保留动态资源，删除唯一的旧菜单 ID 无效读取，并以完整应用资源链接、编译和已有测试验证。执行前备份清单列出的文件；回滚只还原本次修改，不重置其他工作。

## 规划状态

本次为不改变外部行为的内部清理，api_docs 与 product_docs 均为 N/A，无 HTTP 契约变化，无新增或移除用户能力。规划已自审，用户已明确确认执行。仓库缺少 Harness 引导文件、严格验证脚本、产品基线和 OpenSpec CLI，不能宣称对应门禁通过；使用实际静态证据和后续本地构建结果记录验证。
