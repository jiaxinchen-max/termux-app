# Hyprland默认主题要求（规划中）

## 新增要求：m3ww一致视觉

系统应提供以end_4 m3ww为基准的Android适配主题，包括圆角胶囊栏、蓝紫配色、统一字体/图标、协调壁纸、细渐变窗口边框与半透明终端。

### 场景：启用主题

当用户新建Hyprland桌面或为已有桌面明确选择该主题时，应实际加载新主题和服务；在目标设备分辨率下组件不遮挡且触摸操作可用，不出现仍使用旧XFCE默认外观的假升级。

## 新增要求：完整真实交互

桌面应支持应用搜索与启动、真实任务切换、工作区切换、窗口浮动/关闭以及通知；Android电量应反映实际状态。

### 场景：服务或接口不可用

当媒体/网络等可选接口不存在时，应隐藏或明确标示不可用，不显示静态伪造数据和不能执行的操作；必要配套失败时撤销就绪并提供诊断日志。

## 新增要求：渲染能力如实适配

系统应在8位输出下提供可用主题，动画与模糊基于真实设备验证；不得因美化而虚报FP16支持。

### 场景：效果不兼容

当模糊等效果导致渲染异常或明显性能退化时，应能关闭该效果并保持清晰可用的主题；记录测试设备与配置参数。

## 新增要求：配置与会话隔离

主题应按桌面和版本保存，仅在明确启用时改变外观，不覆盖用户编辑文件或全局shell设置。

### 场景：已有桌面升级或回滚

当升级/切换/回退主题时，用户原配置可恢复；停止/故障清理仅处理本桌面所属进程。PRoot入口继续通过既有客户端路由，未设备验证应明确标示。
