# Hyprland 默认外观采用 end_4 m3ww 风格

## 需求与来源

用户指出现有r7桌面简陋，并要求“看看是不是主题的问题，看看人家用的哪套，咱也整一套这么花里胡哨的”。官网首页源码明确将展示视频end_4_rice_intro.mp4署名给end_4。作者仓库历史m3ww配置的胶囊栏、日期/工作区、电量条、Foot和Starship与截图相符；当前main已采用Quickshell，与该旧演示的EWW方案不同。

## 计划行为

以m3ww视觉为基准，将r7默认XFCE面板替换为适配Android的EWW桌面配套：胶囊状态栏、应用搜索入口、工作区和任务切换、圆角通知/日历，统一蓝紫Material色板、图标/字体、星空风格壁纸、圆角窗口和细渐变边框。终端采用Foot、Fish和Starship的协调默认配置。适配触摸尺寸，继续提供窗口关闭/浮动操作。已有用户配置通过版本化主题目录和显式主题选择保留。

先交付原生模式实测；PRoot客户端路由必须保留，未验证不得宣称已通过。音乐模块只在真实媒体会话存在时展示，电量来自已有Android状态桥接；网络/音量等无真实接口时不展示可操作的假控件。动画与模糊按当前渲染能力实测，输出仍为8位。

## 影响与边界

涉及会话配套、安装依赖、主题配置及组件身份；不改变HTTP API，api_docs为N/A。产品文档Required，目标docs/product/desktops.md当前不存在，验收后补充；一致性Pending。本轮不改GNOME/Plasma/XFCE，不执行Git提交/推送或归档。最终构建/部署沿用会话已有授权，但业务修改前仍需确认本方案。

## 验收

对照用户参考图展示实际设备空桌面、两至三窗口、启动器和通知截图；核验布局/字体/颜色一致、触摸入口可用、真实状态无虚构，测试启停与升级保留配置。保留r7回滚路径。详见design.md、tasks.md与specs/desktop-hyprland-theme/spec.md。
