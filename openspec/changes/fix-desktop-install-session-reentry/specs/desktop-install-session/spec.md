# 桌面安装会话

## ADDED Requirements

### Requirement: 安装只执行一次并允许恢复窗口
系统 MUST 为每个活动桌面安装保留唯一任务身份；隐藏安装窗口 MUST 不停止安装，再次点击 MUST 打开同一任务的控制台。

#### Scenario: 隐藏后再次点击
- **WHEN** 用户隐藏正在安装的 PRoot 桌面窗口并点击对应卡片
- **THEN** 显示原任务控制台，日志连续，不重新提交安装且不启动桌面

#### Scenario: 准备阶段或快速点击
- **WHEN** 安装已提交但终端尚未创建，或用户连续多次点击
- **THEN** 所有点击复用同一活动任务，宿主安装命令仅提交一次

#### Scenario: 页面重建
- **WHEN** 用户重新进入或重建桌面列表且安装仍在进行
- **THEN** 可继续查看同一安装会话

### Requirement: 安装状态可见且真实结束
列表 MUST 显示安装中动画与状态直到实际任务结束；状态 MUST 不依赖尚未生成的安装完成清单。

#### Scenario: 安装执行中
- **WHEN** 首次安装或重装处于准备/运行阶段
- **THEN** 卡片显示安装中动画，主操作为查看进度，阻止冲突操作

#### Scenario: 成功或失败
- **WHEN** 安装成功、失败、提交失败或任务异常消失
- **THEN** 解除安装中动画与占用，显示真实结果；失败后的新安装需要用户明确发起，不自动重试

## 四组合审计后的批准范围

用户已批准 native/proot × Wine/desktop 的审计修复。Wine 保留现有动画与控制台，修复 API 至服务落盘之间的任务 ID 空档，提交前原子持久化 QUEUED 任务，提交失败落 FAILED；服务接收已有同 ID 任务并继续准备。公共安装入口识别 Prefix 父任务，允许其已登记的组件依赖。安装中点击卡片、编辑或删除入口均优先恢复该安装会话，禁止无意中断；已进入编辑页的加载流程也检查并回到安装控制台。桌面安装前记录唯一任务并复用；宿主暴露真实终端创建前的有限期提交状态，过期或丢失须失败并取消迟到任务。所有背景状态仅查询真实任务，无启动安装清单检查。
