# 容器导出与 UI 共享存储

## MODIFIED Requirements

### Requirement: 导出身份与当前桌面配置一致
系统必须允许已安装且停止的 Ubuntu resolute PRoot Plasma 和 Debian trixie PRoot XFCE 按既有格式导出，并校验实际 rootfs 发行版身份；导入仍执行既有完整性和路径安全验证。

#### Scenario: 导出 Ubuntu Plasma
- **当** 已停止的 Plasma 容器 os-release 为 ubuntu/resolute，其他前置条件满足
- **那么** 不得因只接受 Debian 的旧入口判断报发行版不支持，并可完成导出和独立导入验证。

#### Scenario: 保留不支持组合及危险路径拒绝
- **当** 实际发行版或代号与桌面配置不一致，或 os-release 解析越出 rootfs、超过大小限制
- **那么** 拒绝导出并给出可理解的原因，不放宽 GNOME 限制或安全规则。

## ADDED Requirements

### Requirement: UI 自动准备外部存储
系统必须在 UI 入口检查外部存储权限与真实访问能力，缺权限时通过系统授权页面申请，授权成功后完成 termux-setup-storage 对应的标准链接初始化，无需切换终端。

#### Scenario: 未授权首次进入
- **当** 用户进入 UI 且外部存储未授权
- **那么** 发起一次系统授权；返回后重新检查，成功后准备链接并验证共享下载目录可读写。

#### Scenario: 已授权但链接缺失
- **当** 外部目录可访问但 ~/storage 或标准链接缺失
- **那么** 自动补全受控链接；已有正确链接保持有效，同名普通文件或目录保留并报告冲突。

#### Scenario: 拒绝或探测失败
- **当** 用户拒绝、撤销权限，或已授权仍无法实际读写
- **那么** 私有目录功能保持可用，不循环弹授权；外部存储操作明确提示失败并允许主动重试，不声称初始化成功。

#### Scenario: 生命周期和回调重复
- **当** Activity 重建、恢复或系统回调重复到达
- **那么** 不并发重复初始化、不无限弹窗，也不重复执行或丢失已等待的备份/导出操作。

### Requirement: 备份保留 snapd 运行时空目录
系统必须保留 rootfs/var/lib/snapd/void 的目录节点及原权限，但不得枚举或归档其中的运行时内容；导入必须拒绝该节点下的内容。不得据此忽略任意不可读用户目录或修改源权限。

#### Scenario: Ubuntu snapd 目录不可枚举
- **当** void 目录权限为 0111，其他持久数据可读
- **那么** 导出成功，独立恢复保留 0111 空目录和其他 snapd 持久数据，源目录不变。

#### Scenario: 其他源目录不可读
- **当** 非既有运行时排除节点无法枚举
- **那么** 导出失败，诊断包含错误码与容器内相对路径，不发布不完整备份。

### Requirement: 恢复后直接使用已有容器
系统必须在发布恢复桌面前完成当前设备所需的本地初始化，保留容器已装软件及用户数据；宿主依赖已经满足时不得因恢复新 alias 再执行完整安装或刷新包索引。恢复成功的桌面必须满足既有已安装判断。

#### Scenario: Plasma 恢复新身份
- **当** 完整 Plasma 容器恢复到新 alias
- **那么** 本地验证已选渲染组合并为新 alias 生成渲染状态，再发布桌面；不重新安装容器软件包。

#### Scenario: DNS 指向运行时目录
- **当** 恢复后的 resolv.conf 指向不持久化的 /run
- **那么** 使用当前宿主有效 DNS 生成普通配置，不写穿符号链接；有效自定义普通 DNS 保留。

#### Scenario: 本地初始化失败
- **当** 所选渲染环境或已有容器依赖不完整导致初始化失败
- **那么** 恢复失败并回滚本任务新建记录/容器/渲染状态，备份和其他容器保留；不以自动完整重装掩盖失败。

#### Scenario: 全新宿主缺少 EGL 诊断工具
- **当** 恢复的宿主渲染模式为 Zink 或 llvmpipe，宿主缺少可执行 eglinfo
- **那么** 在解包前安装必要的 mesa-demos 并复查；仍缺少时报告前置依赖失败，不能把宿主检查判为成功。

#### Scenario: System EGL 无需 Mesa 诊断工具
- **当** 宿主使用 System EGL 且其他依赖已满足，即使没有 eglinfo
- **那么** 不得仅因此安装 mesa-demos 或触发包索引更新。

#### Scenario: 宿主装包替换 API 入口为链接
- **当** 宿主包将 libexec/termux-api 替换为最终符号链接，恢复下一步需初始化 APK 对应 API
- **那么** 安装器必须把链接本身作为可回滚原文件替换为已验证普通入口，不读写其目标；父目录链接仍拒绝，失败及进程退出后须恢复原链接，原备份及容器不受影响。
