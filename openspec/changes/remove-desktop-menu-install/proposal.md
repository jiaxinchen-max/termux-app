# 去除桌面更多菜单中的 Install

## 已确认需求
用户在检查入口差异后，明确圈出 Ubuntu GNOME 卡片更多菜单中的 Install 并要求“这个菜单里的install应该去除”。本变更按该具体指令记录规划和实施授权；替代此前检查报告中“菜单固定保留 Install”的建议。

## 目标及用户可见行为
桌面卡片更多菜单统一移除 Install/安装。该菜单为 Native、PRoot 和各桌面共用，因此全部适用。首次创建后的自动安装、主按钮安装、安装任务进度恢复继续使用已有入口。设置、外部存储、导出、删除、日志及条件性停止/归档进度操作维持现有行为。

## 范围、非目标与兼容性
只删除 DesktopActivity 中的菜单常量、菜单构建及点击分支。安装结果和启动结果混用的问题已单独定位，本次不将状态机重构混入菜单删除，也不宣称该问题已修复。保留已退役 GNOME 的限制。无 HTTP 合约、容器数据、权限、下载协议或组件格式变更。

## 风险、回滚及交付
风险为误删共用安装入口，因此源码审查须确认 confirmInstall、primaryAction 及自动安装调用仍在。仅恢复本次删除的菜单分支即可回滚。执行编译及相关现有回归；删除入口不新增复制实现的测试。构建和核验本地 arm64 APK，原名保持 termux-app_apt-android-7-debug_arm64-v8a.apk。
