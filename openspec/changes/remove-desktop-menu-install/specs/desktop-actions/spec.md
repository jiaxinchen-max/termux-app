# 桌面操作菜单

## MODIFIED Requirements

### Requirement: 更多菜单不提供安装入口
桌面列表的更多菜单 MUST 在各桌面类型、Native/PRoot 模式和生命周期状态下均不展示 Install/安装操作。首次安装及安装进度 MUST 保留现有主操作入口，其他菜单的条件和操作 MUST 保持当前语义。

#### Scenario: 已安装且停止的桌面
- **WHEN** 用户打开已安装桌面的更多菜单
- **THEN** 不出现 Install/安装，设置、外部存储、导出、删除、日志按原条件显示。

#### Scenario: 未安装或正在安装的桌面
- **WHEN** 用户打开其更多菜单或使用主按钮
- **THEN** 菜单不出现 Install/安装；主按钮仍使用原安装流程或返回已有安装任务。

#### Scenario: 其他类型、模式及活动会话
- **WHEN** 用户切换 Native/PRoot、桌面类型或运行状态
- **THEN** 更多菜单始终没有安装项，停止和其他受限操作沿用现有条件。

本规格仅描述删除菜单入口，不声称安装/启动失败状态重构已实现。
