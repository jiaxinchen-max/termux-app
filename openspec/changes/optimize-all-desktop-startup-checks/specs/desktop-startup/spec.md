# 桌面初始化与启动

## ADDED Requirements

### Requirement: 所有桌面初始化完成检验
所有受支持 native/PRoot 桌面必须在保存触发的安装初始化完成之前验证其静态组件、依赖和所选渲染能力。失败必须返回非零状态，不能标记安装成功。

#### Scenario: 初始化发现缺失依赖或损坏组件
- **WHEN** 依赖、组件完整性、所选根文件系统或渲染能力检验失败
- **THEN** 初始化失败并保留错误，不能记录安装成功

### Requirement: 日常启动直接运行
日常启动不得执行静态完整性扫描、缓存检查、依赖导入试运行、合成 GPU 测试窗口、GLX/EGL 能力探测或 apt 安装修复。参数解析、目录安全、会话互斥及真实服务启动就绪/失败处理必须保留。

#### Scenario: 完成初始化后再次启动
- **WHEN** 用户启动任一已初始化桌面
- **THEN** 直接启动真实服务，不调用初始化检验；实际进程错误或退出按已有失败策略终止

#### Scenario: 无显示器初始化
- **WHEN** 保存后的初始化没有正在运行的 Wayland/X11 服务
- **THEN** 使用无显示器 EGL 与依赖检验；实际窗口呈现只由正式运行结果体现，不伪报窗口验证通过

## MODIFIED Requirements

### Requirement: 初始化校验取代旧启动预检
本次用户指令覆盖早期 add-ubuntu-gnome-container 中“启动验证 DING 修复源码”、Hyprland Zink 规划中的启动合成 GPU 测试窗口，以及 optimize-native-gnome-startup-checks 中“PRoot 不变”的旧范围。DING 和组件完整性改为初始化验证，能力以无显示器 EGL 验证，正式会话保留真实运行就绪和失败处理。旧规划作为历史保留，待用户验收和归档时同步正式基线；不得据此声称真实窗口呈现已验证。
