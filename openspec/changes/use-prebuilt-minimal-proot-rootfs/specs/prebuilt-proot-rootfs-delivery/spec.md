# Spec Delta

## Purpose

提供已预装并逐批验证的精简PRoot游戏基础镜像，使用户通过下载和解压即可准备基础运行环境，省去设备上的Debian软件包安装和裁剪过程，同时保持来源可验证、失败可恢复及每游戏前缀独立。

## ADDED Requirements

### Requirement: 预装镜像作为默认基础环境
系统 MUST 在新安装及用户显式重建时使用固定版本的精简预装镜像；设备端不再运行客体apt、locale-gen、Hangover deb安装或裁剪，不静默回退旧构建路径。宿主运行依赖仍须准备。

#### Scenario: 准备全新环境
- **WHEN** 用户准备新的PRoot基础环境且宿主依赖就绪
- **THEN** 系统只下载预装镜像并完成解压校验，不下载Debian基础镜像及Hangover deb源包，进入可创建游戏前缀的就绪状态

#### Scenario: 镜像不可获得
- **WHEN** 镜像下载或校验失败
- **THEN** 系统报告对应失败并可重试，不运行旧的从头安装流程

### Requirement: 镜像身份与运行来源匹配
系统 MUST 校验预装镜像固定版本、压缩载荷摘要及运行清单，区分镜像身份、Wine来源和客户端配方身份，仅在前缀模板与运行来源逐文件匹配时允许准备及启动。

#### Scenario: 镜像或模板不匹配
- **WHEN** 载荷损坏、运行来源不符或模板绑定了不同基础环境
- **THEN** 系统拒绝发布或启动，提供可识别错误，不修改摘要绕过验证

### Requirement: 解压隔离与成员安全
系统 MUST 将镜像解压至任务私有目录，阻止宿主路径逃逸、特殊文件、重复成员、符号链接写穿及超出展开预算，保留必要客体链接并在发布前验证其运行语义。

#### Scenario: 不安全或截断归档
- **WHEN** 归档含危险路径、宿主逃逸链接写入、截断数据或超预算成员
- **THEN** 系统拒绝安装，宿主范围外文件及活动共享根保持不变

### Requirement: 失败和取消保留已发布环境
系统 MUST 仅在新镜像校验成功后原子发布；失败、取消、中断和发布后检查失败保持或恢复原共享根及安装凭据，不删除现有游戏前缀。

#### Scenario: 更新途中取消
- **WHEN** 用户取消镜像解压或任务进程中断
- **THEN** 旧环境及游戏C盘保留，后续重试仅处理归属明确的未发布暂存

### Requirement: 单份共享根和独立前缀
系统 MUST 仅保留一份活动展开基础根，压缩缓存不产生第二份展开组件树；每游戏按匹配模板准备独立可写前缀，不重新完整wineboot初始化。

#### Scenario: 创建两个游戏配置
- **WHEN** 基础环境就绪后依次准备两个全新游戏配置
- **THEN** 两者复用共享根，各自获得独立可写前缀，日志确认跳过完整wineboot生成，基础镜像不重复下载或展开

### Requirement: 资源预算和进度可观察
系统 MUST 依据压缩载荷、新展开根、替换期间旧根及所选前缀计算空间需求，持续报告下载、解压、校验和终态；耗时按实际自然结束记录。

#### Scenario: 空间不足
- **WHEN** 可用空间不足以完成当前安装或替换
- **THEN** 系统在危险写入前报告空间不足，不删除旧环境腾空间或虚报成功

### Requirement: 运行资格和交付边界
系统 MUST 对正式镜像还原后的环境验证PE32/PE64、中文文件和界面、locale、软件图形及音频，并使用原APK文件名交付；静态检查不能替代运行验收或声称所有游戏和硬件兼容。

#### Scenario: 正式包真实App验收
- **WHEN** 用户安装集成正式镜像的新APK
- **THEN** 实际安装、显式重建和两份新前缀的运行证据可追溯至精确镜像摘要，报告耗时和未覆盖范围
