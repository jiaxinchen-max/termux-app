## ADDED Requirements

### Requirement: 共用显示选项
Native 与 PRoot 的新建和设置 MUST 共用分辨率与刷新率策略；分辨率包含 Native、1280x720、1600x900、1920x1080、2560x1440，现有自定义固定值保留。

#### Scenario: 查看两种模式的同一桌面
- **WHEN** 用户查看同一桌面的新建或设置
- **THEN** 显示选项一致；GNOME 固定 60 Hz 并说明当前后端限制，其他可创建桌面可选 30/60/90/120 Hz。

### Requirement: Native 输出贯通
系统 MUST 保存 native 选择，并在每次新会话开始时按窗口像素尺寸解析；视图与合成器使用同一尺寸。重新进入活动会话 MUST 使用其已启动尺寸。

#### Scenario: 保存、恢复或重新启动
- **WHEN** Native 设置经过仓库及存档往返，或设备窗口尺寸改变后重新启动
- **THEN** 选择仍为 Native，新启动使用当前有效尺寸，不重新安装或初始化桌面。

### Requirement: 准备结果保持边界
GNOME 与 Hyprland MUST 允许仅数值几何变化，保留其他准备参数匹配和尺寸合法性检查。

#### Scenario: 启动尺寸变化
- **WHEN** 新会话尺寸与安装准备时不同
- **THEN** 合成器收到本次有效尺寸；改变身份、主题、渲染器或刷新率仍要求重新准备，非法尺寸启动失败。
