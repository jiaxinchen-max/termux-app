# 设计

LocalGamesActivity.showActionsTextMenu 删除引擎配置、资产、备份和重新授权的重复菜单项，仅保留 Edit、Remove。弹窗宽度按这两个标签计算，不再依赖后端或文件访问状态。横竖屏复用该实现，保持原有窗口边界和滚动约束。

Edit 继续调用游戏编辑页，Remove 继续确认后调用卸载流程，两者现有强杀逻辑保留。启动弹层图标菜单及编辑器内功能不属于本次范围。

通过实际卡片菜单渲染与点击回归覆盖两后端、横竖屏和授权状态；核对编辑路由与删除确认、取消不删除。执行编辑/删除既有强杀回归。

风险仅限菜单遗漏或宽度不适合两个标签；保留48dp触摸目标和窗口限宽。回滚只恢复本次快照，不覆盖已有脏工作树。不涉及新受保护路径、资产、Git或部署操作。
