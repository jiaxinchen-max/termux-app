## 组件与原生后端

第一阶段在指定编译机隔离新增配方及补丁，固定源码提交、依赖版本、校验和、工具链及构建日志。用户进一步指定基于仓库最新 main：固定 70ec30e71656bce5e1af3364129421a4386a69e1（0.57.0），使用其 flake.lock 固定 Aquamarine/hypr* 依赖；此前 0.45.0 仅作历史评估记录。0.57 默认配置改为 Lua，客户端配置按新格式实现。依赖通过现有 build-package.sh 和现有网络配置构建，不替换用户此前定制。

为 Aquamarine/Hyprland 接入现有 Android `termux-render` 显示与输入协议，复用已实现的传输和 Android 资源生命周期。实现无 DRM 的 Android EGL/缓冲区路径，逐项验证 AHardwareBuffer、共享内存或 dmabuf 的实际支持，按能力协商同步和格式，禁止对不支持的 DRM 显式同步虚报能力。不能以嵌套 KWin 绕过原生后端。

首期仅承诺 system 模式，必须在组件实际呈现窗口、响应输入后才能生成安装契约。产物清单记录仓库、真实发布标识、文件名、架构、依赖和 SHA-256；不存在的发布版本和哈希不得写入脚本。公开发布前另取授权；本地可用测试产物及 APK 构建不等于已发布可下载。

## 应用与组件下载边界

`DesktopCreationCatalog`、`DesktopRendererPolicy`、`DesktopCreateActivity` 同步开放 Hyprland，显式限制 system 模式；不能只改全局 isCreatable 而意外开放其他渲染器。原生单实例、PRoot 独立容器规则保持一致。现有 USB 共享限制保持不支持 Hyprland。

`desktop_install.sh` 增加类型、组件清单、架构校验、安装结果检查。PRoot 只安装客户端环境，合成器安装在宿主。必须核验 Hyprland、匹配动态库、Xwayland、终端、文件管理器及必要会话服务。客户端候选沿用现有 XFCE 终端和文件管理器；先验证仓库包和模式兼容性，再锁定清单，不能依赖设备偶然已装的软件。

继续使用现有下载与任务日志机制；安装失败退出非零且不写成功标记，重试不得覆盖用户已有配置。安装检查包含运行时依赖，不以单个可执行文件存在代表就绪。

## 会话、Service、显示和输入边界

`DesktopLaunchSpec` 增加独立 Hyprland 启动契约和组件版本字段。`desktop_start.sh` 在 KWin 环境初始化前分派 Hyprland；清除不适用的继承变量，明确设置自己的后端参数。Service 和任务管理沿用现有通道，不另建常驻 Android 服务。

每个桌面拥有独立 runtime、Wayland socket、日志、会话 PID 和就绪记录。建议采用 `~/.termux/hyprland-<desktop-id>/`，权限及路径经过统一校验。PRoot 仅绑定当前桌面所需 socket、音频及文件路径，宿主合成器服务容器客户端，退出后清理绑定状态。

复用 `DesktopSessionActivity`/`X11SessionView` 的显示和输入入口，验证触摸指针、键盘、组合键、焦点、窗口切换、分辨率和刷新率。默认配置提供终端和文件管理器入口及平铺窗口操作，避免仅有依赖实体键盘的快捷键。

`DesktopEnvironment` 和 `DesktopTasks` 增加独立安装/就绪判断。运行状态需要本次 supervisor 存活、对应 Wayland socket 可连接、带当前 PID 的就绪记录及真实后端握手；安装失败、崩溃、旧 socket/旧 marker 均不能显示运行中。首帧回调可参与界面展示，但黑帧不是验收证据；验证必须打开窗口并完成输入。

`desktop_stop.sh` 使用当前桌面 supervisor/进程组和准确的 socket 归属清理，不按全局进程名杀其他桌面。强退、应用重启、重复启停均不能重用过期 marker。默认配置与用户文件保存在桌面私有目录，停止不删除持久配置。

## 归档与兼容性
