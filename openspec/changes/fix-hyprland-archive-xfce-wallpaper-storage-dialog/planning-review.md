# 规划自审

已直接阅读菜单、归档策略/元数据/导入构造、宿主前置安装、恢复 wrapper、XFCE 初始化及会话入口、USB 控件与各后端约束。用户截图对应 USB 卷桥接，并非共享下载目录权限弹窗；不混淆两条流程。

Hyprland 缺少导出并非只漏一个枚举：旧规格明确排除，需要新增可信组件准备、身份完整保留及失败事务回归。本规划明确将其作为新的支持范围，并保留 USB 与渲染边界。

XFCE 日志显示确切缺失路径，壁纸包与其他图像已存在。规划不凭此断言所有图像解码均正常，要求实际解码和画面证据。存储按钮禁用包含既定功能限制，规划不把有意禁用误改为无条件可用。

补充只读探针：容器没有 `gdk-pixbuf-thumbnailer` 命令；通过 GdkPixbuf 库读取图像的远端探针在 ADB 等待期限内未返回，未取得解码结果。没有因此安装诊断包、替换图像库或更改壁纸配置；后续验证须区分路径修复与解码可用性。

回退、现有数据保护、交互前 force-stop、深浅主题、后台异常恢复和新归档在旧 APK 的拒绝语义均已纳入。未发现未处理 MUST_FIX；这是规划自审通过，不等于用户确认、代码审查或产品验收。缺失严格门禁和资料基线如实登记。
