# 界面外观

## MODIFIED Requirements

### Requirement: 桌面选择弹窗统一适配深浅色

桌面创建和编辑中的选择弹窗必须采用模块现有主题封装，跟随当前 UI 深浅色设置，保持原有候选、选中值、选择和取消行为。

桌面编辑父面板同样必须使用统一的深浅色遮罩规则，不得因子弹窗已适配而继续保留浅色模式下的黑色 dim。

#### Scenario: 浅色打开并选择参数

- **WHEN** 浅色模式下从桌面创建页或编辑面板打开参数选择框
- **THEN** 弹窗采用统一窗口背景及暖色遮罩，不使用黑色窗口 dim
- **AND** 选择有效参数后关闭选择框并更新当前显示值
- **AND** 关闭后清理该弹窗的遮罩，编辑面板仍保留

#### Scenario: 深色打开和取消

- **WHEN** 深色模式下打开参数选择框并取消
- **THEN** 采用统一深色窗口和 dim 处理
- **AND** 参数保持不变且不遗留遮罩
