# 内嵌文件浏览器操作

## ADDED Requirements

### Requirement: 文件和目录上下文操作
文件浏览器 MUST 为允许操作的文件和目录提供打开、复制、剪切、删除。

#### Scenario: 长按项目
- **WHEN** 用户长按文件或非根目录
- **THEN** 菜单针对该项目，文件仍可导入游戏；短按原行为保留

#### Scenario: 长按空白
- **WHEN** 用户在某子目录内容间隙或剩余空白视口长按
- **THEN** 不弹出菜单，也不执行文件操作

#### Scenario: 三个固定根目录保护
- **WHEN** 用户长按首页三个入口，或试图对其对应根目录进行复制、剪切、删除、打开
- **THEN** 不提供该根目录的对象操作；执行层同样拒绝，根内部普通子项仍可操作

### Requirement: 复制和剪切通过粘贴完成
浏览器 MUST 提供跨目录的单项复制/剪切与粘贴，写操作串行执行。

#### Scenario: 复制目录
- **WHEN** 复制目录后进入目标目录并粘贴
- **THEN** 复制完整内容，包括隐藏子项，源保持存在，列表刷新

#### Scenario: 剪切目录
- **WHEN** 剪切后尚未粘贴，或粘贴目标写入失败
- **THEN** 不提前删除源，不自动回退为其他操作

#### Scenario: 成功移动
- **WHEN** 剪切粘贴的目标完整写入并成功发布且源删除成功
- **THEN** 原项目移除，清空剪切状态并更新目录

#### Scenario: 粘贴到根目录
- **WHEN** 有待粘贴项目并进入允许访问的根目录
- **THEN** 可通过工具栏的粘贴操作将其放入根目录，但根目录本身仍不能作为对象操作

#### Scenario: 冲突或非法目标
- **WHEN** 目标同名、源和目标相同、目录被复制到自身子树或路径越界
- **THEN** 明确失败，不覆盖、合并或自动改名

### Requirement: 删除需要用户确认
删除 MUST 先显示对象名称并取得确认。

#### Scenario: 取消删除
- **WHEN** 用户取消文件或目录删除确认
- **THEN** 所有原有内容保持不变

#### Scenario: 删除失败
- **WHEN** 删除非空目录中途遇到错误
- **THEN** 停止并显示失败或部分完成情况，不隐藏失败，不继续处理其他对象

### Requirement: 系统文件打开方式
“打开” MUST 使用注册该 MIME 类型的 Android 应用处理，遵循系统默认选择。

#### Scenario: 有对应处理应用
- **WHEN** 用户点击打开文件或非根目录
- **THEN** 通过 ACTION_VIEW 和准确 MIME、content URI 及临时只读授权发起，系统默认应用或解析界面处理

#### Scenario: 无对应应用
- **WHEN** 系统没有对应类型处理应用
- **THEN** 明确提示，不能伪装打开成功或自动换成游戏运行

#### Scenario: 内容访问范围
- **WHEN** 外部应用访问获授权项目
- **THEN** 只能读取所选文件或目录子树，不能写入或访问授权范围以外的资料

### Requirement: 点号文件显示开关
浏览器 MUST 支持显示和隐藏名称以点号开头的文件及目录。

#### Scenario: 默认及切换
- **WHEN** 初次打开浏览器或切换工具栏“显示隐藏文件”选项
- **THEN** 默认隐藏点号项目，勾选后立即显示，取消后立即隐藏，普通项目不受影响

#### Scenario: 状态保留与复制内容
- **WHEN** 用户重建界面、切换目录或复制含隐藏子项的目录
- **THEN** 显示偏好保留，复制仍包含隐藏内容而不受显示过滤影响
