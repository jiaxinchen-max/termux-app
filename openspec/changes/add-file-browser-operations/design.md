# 设计

## 当前实现
GameFileManagerActivity 通过 java.io.File 浏览三个固定入口：GameStoragePaths.getImportedGamesDirectory、getFilesDir 和共享存储。目录短按导航，文件短按详情、长按仅导入游戏；FileObserver 合并刷新事件，单线程 ioExecutor 执行导入任务。空白区域不绑定长按或手势菜单监听。

## Activity、菜单和状态
在文件浏览器内绑定项目上下文菜单，菜单标题标明对象。根保护采用三个根目录的规范化路径准确匹配，包含从私有根浏览到游戏根时的同一对象以及符号链接别名。操作执行层再次检查根保护，不能只依赖菜单隐藏。
复制/剪切采用浏览器内部单项待粘贴状态，包含源路径与操作类型；导航、横竖屏及正常重建保留。进程恢复不得自动执行操作，粘贴时重新检查来源。粘贴和取消统一放在工具栏。根目录不做对象菜单，但可作为目标目录粘贴。
显示隐藏文件状态存储在文件浏览器独立偏好中，初次默认隐藏点号项目。过滤在构建目录列表前执行，过滤后无可见内容显示空状态。切换时保留当前路径，不改变排序和视图模式。

## 文件操作边界
提取可测试的文件操作类，复用三根路径的访问范围，校验路径分隔符边界，拒绝越界。复制/移动递归处理目录，包含隐藏子项；文件流逐块复制，在目标父目录的独占暂存位置写入，完成后才发布最终同名项，不覆盖已有文件。剪切仅在复制完成且发布成功后删除源，删除失败明确报告，不声称已完成。暂存失败清理本次创建的暂存树，不触碰原有目标。
符号链接按链接本身处理，不追踪目录链接递归删除或复制；目标文件系统不支持保存链接时明确失败。拒绝源/目标相同、目录复制到子目录以及受保护根作为来源。删除前 UI 二次确认，执行过程遇到错误停止并明确显示；若已删除部分内容必须如实提示，不能声称自动回滚。
所有写操作串行进入现有 IO 边界，忙碌时禁用冲突操作；FileObserver 刷新和主动刷新协调，防止旧目录回调覆盖新目录。复制/剪切不调用 shell、Wine、prefix 或游戏库更新接口。

## 系统打开与内容提供
使用带准确 MIME 的 ACTION_VIEW，设置临时只读 URI 授权及 ClipData，由 Android 使用已配置默认应用或系统解析界面。未知扩展名使用 application/octet-stream，目录使用 vnd.android.document/directory；没有处理应用明确提示。不会强制 chooser 破坏用户默认设置。
现有 TermuxOpenReceiver.ContentProvider 依赖额外外部应用策略开关且 getType 返回 null，MTDataFilesProvider 范围也不覆盖全部共享存储；不直接放宽其规则。计划新增专用于文件浏览器的只读 DocumentsProvider，提供名称、大小、MIME 和只读文件打开/目录查询。authority 从 applicationId 派生；通过 DocumentsContract URI 临时授权，文件只授权所选文件，目录授权所选子树，不授权三个根。Provider 不允许写、改名、删除或创建，不将文件浏览器未授权路径暴露给第三方。
新增 Provider 的 Manifest 注册需明确 grantUriPermissions、exported 和 MANAGE_DOCUMENTS 访问边界，并用无授权、只读授权、越界、编码路径和符号链接测试验证。不修改 Termux 原有 Provider 或允许外部应用的全局策略。

## 其他系统边界
Service 和下载组件流程、shell、X11、游戏运行后端不变。保持既有共享存储权限申请和返回续办逻辑；权限撤销时明确提示。用户文件操作不迁移旧游戏路径。核心组件目录虽在私有文件浏览范围内，不新增运行时自动修复或回退。

## 验证
操作单元测试：文件/目录复制、剪切后粘贴、完整性、隐藏内容、同名拒绝、相同/子目录拒绝、三根及嵌套根保护、符号链接不跟随、缺失源/权限错误、失败和部分删除提示。
Robolectric 页面验证：网格/列表、横竖屏、项目长按、空白长按无菜单、准确对象、首页/根限制、粘贴/取消、删除确认与取消、隐藏开关及状态恢复、保留导入操作。
Provider/Intent 验证：ACTION_VIEW、MIME、content URI、ClipData、只读授权、根保护、文件读取和目录查询、越界与写入拒绝、无匹配应用提示。Manifest 合并结果纳入 APK 检查。
最后运行相关已有浏览器导航/刷新回归并编译固定命名 arm64 普通 debug APK，testOnly=false。用户手动安装测试真实第三方应用打开，自动测试不操作设备上的真实资料。

## 风险和回滚
Manifest/Provider 为需重点审查的访问边界，用户对本方案的批准覆盖新增只读 Provider 注册，不涉及既有 Provider 放宽。当前 Harness 保护路径规则文件缺失，不能声称完成其门禁；记录影响、快照、验证与授权。撤销 Provider 注册、操作类和菜单资源可回退功能，不恢复真实删除或移动的数据。产品知识在用户最终验收后才定稿。

## 2026-11-10 取消空白长按
用户确认尝试修复后仍无菜单，明确要求取消此功能。移除空白长按回调、滚动手势监听及空白菜单分支；保留项目长按、工具栏粘贴/取消和根目录保护。验证横竖屏空白触摸不弹菜单，项目菜单与工具栏操作仍有效。
