# 内嵌文件浏览器增加文件操作

## 需求和目标
为目录和文件提供复制、剪切、删除、打开，并补齐复制/剪切所需的粘贴。长按项目对该项目操作；长按目录空白区域对当前目录操作。首页的游戏文件、私有文件、共享存储三个固定入口，以及对应根目录本身，不允许作为复制/剪切/删除/打开的操作对象。支持按名称是否以点号开头显示或隐藏项目。

## 用户可见行为
- 文件/目录长按弹出打开、复制、剪切、删除；文件保留原有导入游戏入口。短按目录仍进入浏览，文件短按仍显示详情。
- 空白处长按菜单明确显示当前目录名称，操作对象为当前目录，不会误指向上次选中项目。剪贴板有内容时提供“粘贴到此目录”；三个受保护根目录仅允许作为粘贴目标，不提供根目录对象操作，首页三个入口无对象操作菜单。
- 剪切先记录来源，不立即移动。进入目标目录后粘贴才执行；复制保留原文件，剪切仅在目标完整写入后删除来源。完成后刷新目录，剪切成功清空待粘贴记录。提供取消待粘贴操作。
- 删除文件或非空目录须确认，删除后若当前目录失效返回可用父目录。删除不进回收站。
- “打开”使用 Android ACTION_VIEW 和文件 MIME 类型，交由系统默认处理应用；没有默认应用时使用系统解析选择界面，不强制自建应用列表或固定第三方包名。目录使用 Android 目录文档类型；无匹配处理应用时明确提示，保留内嵌目录短按浏览。
- 工具栏提供“显示隐藏文件”可勾选项，默认关闭，记住选择，立即同时影响点号文件和目录。复制/剪切目录时仍包括其隐藏内容。

## 冲突和错误规则
目标同名、源和目标相同、目录复制到自身/子目录、来源失效或无权限均明确失败，不覆盖、不合并、不自动改名。操作串行后台执行，UI 显示忙碌状态，防止重复提交。失败不自动换路径、换打开方式或重试。

## 范围与非目标
仅文件浏览器及其文件操作/外部打开支持代码。不是多选管理器，不新增重命名、压缩解压或回收站，不修改游戏启动、prefix、Box64 或核心组件。文件操作不自动编辑游戏库中的路径或删除游戏卡片。

## 文档、风险及回滚
api_docs 为 N/A：不改变 HTTP 契约；Android 内容 URI 授权不是 HTTP API。product_docs 为 Required，验收后维护 docs/product/file-manager.md，一致性 Pending。用户批准后实施，真实文件删除只由用户在界面确认触发；自动测试使用临时文件。外部打开仅授予所选文件/目录临时只读访问，不授予整个私有根目录。记录 Provider/Manifest 变动的影响、验证和回滚。回滚仅撤销本次代码和资源，已执行的用户文件操作不能靠代码回滚恢复。
