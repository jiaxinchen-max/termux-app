# 取消游戏控制抽屉的全屏半透明遮罩

## 目标与用户可见行为
用户打开游戏控制抽屉时，抽屉外的游戏画面保持原有亮度和颜色，不再覆盖全屏半透明底色。Native、PRoot、横屏、竖屏、浅色与深色模式统一适用。

## 范围与非目标
仅把游戏会话 game_session_drawer_layer 的背景从 local_games_scrim 改为透明。保留全屏容器用于点击外部关闭抽屉，保留抽屉面板底色、动画、返回键/手势及输入拦截。共享颜色定义仍供桌面会话使用，不修改桌面会话或共享颜色。

## 文档与兼容性
无 HTTP 契约变更，api_docs 为 N/A。用户可见交互变化，product_docs 为 Required，拟在用户验收后维护 docs/product/game-session.md，一致性 Pending。无数据格式变化或兼容性迁移。

## 风险、验证与回滚
保留外部点击拦截，避免透明区域点击落入游戏。核对资源和运行时代码无额外背景设置，编译 APK 并检查打包布局，运行已有返回策略回归；用户手动验证视觉和点击操作。回滚仅恢复该布局的原背景，不覆盖工作区其他修改。
