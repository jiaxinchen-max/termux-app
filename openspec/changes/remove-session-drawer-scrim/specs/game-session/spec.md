# 控制抽屉背景

## MODIFIED Requirements

### Requirement: 控制抽屉外的游戏画面不被遮罩染色
游戏会话打开控制抽屉时 MUST 保持抽屉外游戏画面原有亮度和颜色。

#### Scenario: 打开游戏控制抽屉
- **WHEN** 用户在 Native 或 PRoot 游戏会话打开抽屉
- **THEN** 游戏画面上没有全屏半透明底色，抽屉面板保持自身背景

#### Scenario: 不同方向与主题
- **WHEN** 用户在横屏、竖屏或深浅色模式下打开抽屉
- **THEN** 抽屉外背景均透明

#### Scenario: 透明区域关闭抽屉
- **WHEN** 用户点击抽屉外透明区域
- **THEN** 仍关闭抽屉，该点击不传递到游戏；系统返回仍按原有层级导航和开关抽屉
