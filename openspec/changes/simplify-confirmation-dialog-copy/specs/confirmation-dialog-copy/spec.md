# 二次确认文案

## 新增要求

### 要求：简短表达操作影响
现有操作确认正文应以简短单段说明结果，优先一句话，去除重复询问和实现过程。

#### 场景：用户确认删除或覆盖
正文明确将被删除或覆盖的对象；永久删除提示无法撤销。可选删除范围继续通过原有选项表达，不能暗示未勾选的数据也会删除。

#### 场景：用户退出游戏或终止会话
正文说明执行会终止当前运行和可能丢失未保存内容，不枚举内部进程。

#### 场景：用户安装、重建或恢复环境
正文说明新增或替换的环境和必要的数据影响，不解释下载缓存、校验、包管理器和解压步骤，不声称未核实的数据保留或兼容性。

#### 场景：用户选择保存或放弃编辑
正文说明保存生效对象与放弃修改的影响；现有保存、放弃和取消行为不变。

### 要求：修改局限于确认表达
默认英文与简体中文应保持相同含义和原占位符，保留必要限制、原按钮、复选框和执行分支；不增加或删除确认步骤。
