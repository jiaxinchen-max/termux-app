# 二次确认文案预览

以下文案已获用户批准，现已实施。英文默认资源同步表达相同含义；标题、按钮、选项及操作逻辑保持当前行为。

| 场景 | 当前中文 | 拟用中文 |
|---|---|---|
| 恢复 C 盘 | 使用所选备份替换此配置的 C 盘和 Wine 注册表？共享运行环境、应用配置和盘符映射会保留。备份必须使用相同的 Wine 版本。 | 将用所选备份覆盖此配置的 C 盘和注册表，请使用相同 Wine 版本的备份。 |
| 安装 Native 环境 | 这会下载并安装启动 GLIBC 游戏所需的运行环境（Wine、X11、显卡驱动），可能需要几分钟。 | 将下载并安装 Native 游戏运行环境。 |
| 安装容器环境 | 下载并解压已预装 Hangover 和字体的精简 RootFS。每个游戏使用独立的 Wine 前缀。 | 将下载并安装已包含 Hangover 的容器运行环境。 |
| 重建 Native 环境 | 将通过包管理器移除 Native（GLIBC）运行环境及已下载的组件，然后重新下载并安装，可能需要几分钟。 | 将删除并重新安装 Native 运行环境及已下载的组件。 |
| 重建容器环境 | 下载或复用缓存中的精简 RootFS，校验后替换共享基础环境，保留现有游戏前缀。安装失败时保留当前基础环境。 | 将替换容器基础环境，保留现有游戏数据。 |
| 恢复基础环境备份 | 这会用所选备份替换当前共享的 RootFS 基础环境和 Wine 前缀模板。已安装的游戏仍可使用，可能需要几分钟。 | 将用所选备份覆盖当前容器基础环境和运行模板。 |
| 备份是否包含模板 | 模板是新游戏克隆用的现成 Wine prefix,可以重新生成。不包含可以让备份更小,恢复时会重新生成它们,多花几分钟。 | 包含运行模板会增加备份大小。 |
| 移除游戏配置 | 将移除此配置、私有封面及未被其他配置使用的容器数据。共享运行环境和原始游戏目录将保留。 | 将删除此游戏配置及不再共用的容器数据，保留原始游戏文件。 |
| 退出游戏 | 将终止游戏、Wine、音频和显示进程，未保存的进度可能丢失。 | 将强制结束游戏，未保存的进度可能丢失。 |
| 切换应用模式 | App 进程将重启。请先安全退出正在运行的游戏和终端 Session。 | 将重启应用，请先退出正在运行的游戏和终端会话。 |
| 保存或放弃修改 | 更改仅应用于 %1$s。 | 保存后将应用于“%1$s”，放弃则丢弃本次修改。 |
| 删除文件或目录 | 永久删除“%1$s”？若为目录，将删除其中所有内容。 | 将永久删除“%1$s”及其全部内容，无法撤销。 |
| 覆盖同名文件 | 同名文件已存在，将被替换。 | 将覆盖已有的同名文件。 |
| 安装桌面 | 将下载桌面所需包(首次使用还包括容器 rootfs),可能需要几分钟。继续? | 将下载并安装此桌面所需的运行环境。 |
| 删除桌面 | 将移除桌面条目与会话状态,运行中的进程会先被停止。 | 将停止此桌面并删除其条目和会话状态。 |
| 导出桌面 | 仅导出此容器和桌面设置。请选择新文件名，已有文件不会被覆盖。 | 将把此容器和桌面设置备份到 Download/Termux/backups/。 |
| 导入桌面 | 导入容器和桌面设置。将先检查并安装所需宿主组件，失败时停止导入。保留归档中的明确渲染设置。 | 将从所选文件导入桌面容器和设置。 |
| 安装显示服务 | Xlorie 是独立的 X server 软件包，目前尚未安装。现在安装吗？Xlorie 暂不支持 Vortek Vulkan（glibc 游戏）。 | 将安装 Xlorie 显示服务，该服务暂不支持 Vortek Vulkan。 |
