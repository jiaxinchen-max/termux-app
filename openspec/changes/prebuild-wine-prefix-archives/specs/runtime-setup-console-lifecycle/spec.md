# 运行环境准备控制台生命周期

## Purpose

确保运行环境准备控制台在用户离开页面、重新进入、旋转屏幕以及后台任务异步结束时仍能正确展示持久任务状态，安全结束界面观察，防止窗口失效引发应用崩溃，并保留失败日志和显式取消语义。

## ADDED Requirements

### Requirement: 任务完成回调在失效窗口上安全处理

准备任务完成时界面 MUST 仅在所属页面与窗口有效时更新和关闭，重复完成或关闭回调 MUST 幂等。已销毁或脱离窗口的控制台 MUST 停止界面观察，不因移除无效 View 导致应用主线程崩溃。

#### Scenario: 准备中离开并重新进入

- **WHEN** 用户在准备期间离开页面再进入，旧界面收到后台成功回调
- **THEN** 应用不崩溃，新界面从持久任务获得成功状态
- **AND** 已成功任务不被重复完成、误取消或重新启动

#### Scenario: 重复关闭与页面旋转

- **WHEN** 页面旋转/销毁与任务完成、用户关闭操作发生交错
- **THEN** 每个界面安全结束观察，窗口资源不被重复移除
- **AND** 不把非生命周期异常静默吞掉

### Requirement: 控制台生命周期不改变持久任务结果

界面关闭、观察停止与用户显式取消任务 MUST 区分；后台成功、失败或取消状态 MUST 由现有任务管理者持久化。失败日志 MUST 可重新查看，控制台释放后 MUST 不继续轮询和引用已销毁页面。

#### Scenario: 关闭观察界面后任务继续

- **WHEN** 用户离开控制台而未显式请求取消准备
- **THEN** 后台准备遵循原任务生命周期，重新进入后显示其持久状态

#### Scenario: 准备失败或显式取消

- **WHEN** 任务失败或用户通过既有操作取消任务
- **THEN** 重新进入可看到对应结果与失败日志
- **AND** 不显示成功、不发布半成品前缀
