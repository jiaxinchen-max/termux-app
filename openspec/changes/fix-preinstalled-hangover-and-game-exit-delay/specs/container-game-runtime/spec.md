# 容器游戏运行时

## MODIFIED Requirements

### Requirement: Hangover为镜像预装运行时
容器模式必须将Hangover标注为随镜像预装，支持选择，不能要求或提供Hangover单独安装。基础镜像准备状态与独立Wine安装状态分开表达，启动仍要求真实环境就绪。

#### Scenario: 首次导入尚无基础镜像
- **WHEN** 导入容器游戏并查看默认Hangover
- **THEN** 展示随容器预装及保存时准备容器说明，不显示所选Hangover未安装；不能在准备完成前启动。

#### Scenario: 镜像就绪或关键文件缺失
- **WHEN** 查看已准备的容器运行时
- **THEN** Hangover显示镜像预装；若已完成镜像缺少关键文件则明确环境不完整，不进入独立Hangover安装或重建回退。

### Requirement: 主动退出快速清理当前会话
用户确认退出必须终止当前会话及关联子进程，取消原25秒自然退出等待；必须真实完成清理后结束任务，失败必须可见，不误杀其他容器或App主进程。

#### Scenario: 用户主动退出
- **WHEN** 用户确认退出仍运行的游戏
- **THEN** 快速终止本次会话，经过有界短清理确认后返回列表，不留下后台游戏进程，不进入25秒或额外15秒优雅等待。

#### Scenario: 游戏自然结束
- **WHEN** 游戏自行正常结束
- **THEN** 保留正常注册表落盘与有界清理，不将自然退出等同于用户强制退出。
