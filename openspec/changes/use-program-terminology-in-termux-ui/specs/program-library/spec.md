# 程序用语

## MODIFIED Requirements

### Requirement: 界面统一使用程序用语

termux-ui 的产品显示文本必须按运行任意 Windows 程序的定位使用英文 program／programs 或中文“程序”，不能将对象称为 game／games 或“游戏”。包括标题、按钮、提示、帮助、通知、无障碍名称、组件版本说明及本模块可见启动日志。游玩和已玩时间改为运行和上次运行。

#### Scenario: 打开详情和启动
- 当用户查看截图中的详情弹层
- 则英文标题和按钮为 About this program 和 Launch program，简体中文使用“程序介绍”和“启动程序”。

#### Scenario: 查看导入、编辑和运行状态
- 当用户查看程序导入、编辑、运行环境准备、会话状态、退出或组件版本
- 则产品文本统一称为程序，并保留现有动作、错误行为和准确技术名称。

#### Scenario: 保留运行标识
- 当文案调整应用到既有程序配置
- 则内部标识、真实文件路径、组件ID、协议和存储不变，用户自定义名称不被篡改，不触发重新初始化或迁移。
