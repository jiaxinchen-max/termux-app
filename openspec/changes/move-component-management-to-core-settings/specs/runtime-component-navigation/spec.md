# 运行组件管理导航

## ADDED Requirements

### Requirement: 核心组件设置提供独立管理入口
系统应在“设置 → 核心组件 → Native / Proot”提供对应后端的组件管理入口，复用已有分类与版本管理能力。

#### Scenario: 尚未导入游戏
- **WHEN** 用户从Native或Proot设置页进入组件管理
- **THEN** 应显示该后端支持的组件，不要求游戏ID或编辑草稿，安装及状态刷新可用。

#### Scenario: 返回与重建
- **WHEN** 用户返回组件分类的上一级或系统重建页面
- **THEN** 返回对应后端设置页或恢复正确后端及分类，不显示另一后端的缓存内容。

### Requirement: 游戏编辑只配置当前游戏
系统应移除游戏编辑页Components全局管理入口，保留当前游戏Wine版本选择、当前选择显示及其他逐游戏组件配置。

#### Scenario: 选择后放弃或保存
- **WHEN** 用户选择其他Wine并放弃或保存
- **THEN** 放弃保留原选择；保存使用新选择；新导入游戏放弃时不发布游戏卡片。

### Requirement: 管理操作不修改游戏选择
从设置进入版本页必须采用管理模式，不隐式更新任何游戏档案的Wine选择。

#### Scenario: 安装全局组件
- **WHEN** 用户在设置安装一个Wine版本后返回
- **THEN** 已有游戏配置保持原选择，编辑页可通过Wine选择器显式选用新版本。

#### Scenario: 启动时缺失组件
- **WHEN** 启动缺失组件提示引导用户管理组件
- **THEN** 应进入该游戏后端对应的设置组件管理，不进入已移除的编辑管理入口。
