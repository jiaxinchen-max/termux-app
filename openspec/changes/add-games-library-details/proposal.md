# Games 游戏库、封面与详情提案

## 背景

SAF 导入已能保存 Game，但游戏库仍只有空态，用户无法查看已导入游戏、目录权限、封面或修改导入信息。该分片完成本地游戏资产的日常管理闭环。

## 目标

- 从 `FileGameRepository` 加载完整游戏库，并展示封面、名称、EXE、最近游玩和目录权限状态。
- 提供模块私有详情 Activity，支持编辑名称、工作目录和启动参数。
- 支持从本地图片导入私有封面、替换和移除，不依赖网络。
- 区分可访问、权限丢失、Provider 不可用，并提供重新授权入口。
- 安全删除仅移除私有 Game 记录和私有封面，不删除用户游戏目录。

## 非目标

- 不提取 Windows PE 图标，不下载网络封面或游戏元数据。
- 不实现 RuntimeProfile、启动任务、X11 会话或存档管理。
- 不修改主 app、TermuxService、脚本、X11、native 或 build 文件。

## 用户可见行为

游戏库展示所有已导入游戏。点击卡片进入详情；权限丢失时卡片和详情明确提示并可重新授权。用户可修改信息和封面，也可确认删除库记录，原始目录不会被删除。

## 影响范围

仅修改 `:games` Activity、module manifest、library/artwork 数据代码、资源、测试和对应 OpenSpec/Harness/领域文档。

## 风险与回滚

- 大图：私有封面限制源文件大小与像素边界，列表按目标尺寸采样解码。
- Provider 卡顿：权限可读性探测在后台执行，Activity 只展示 snapshot。
- 删除误解：确认文案明确仅删除库记录和私有封面。
- 回滚：删除新增详情、library/artwork 代码与资源即可，已有 Game properties 和用户目录不变。
