# Spec Delta

## Purpose

为已安装Hangover的PRoot游戏运行环境定义可审计的体积裁剪、候选验收及发布边界，在尽量缩小基础环境的同时保留已声明的中文、图形、音频与双位数运行能力，使空间收益和功能损失可以分别验证。

## ADDED Requirements

### Requirement: 裁剪输入与变更可追溯

系统 MUST 只接受具有完整身份且停止写入的已安装运行环境，输出输入/输出摘要、逐路径删除清单、保护项与逻辑/实体/压缩体积。系统 MUST NOT 将游戏C盘节省或缓存清理伪称运行本体缩减。

#### Scenario: 已安装候选精简
- **WHEN** 从固定Hangover版本的已安装环境创建精简候选
- **THEN** 报告可以追溯所有删除内容和实际节省，运行二进制身份保持不变

#### Scenario: 输入身份不完整
- **WHEN** 输入是游戏前缀、版本不匹配或安装未结束
- **THEN** 系统明确拒绝且不修改输入

### Requirement: 保留运行功能与初始化来源

精简环境 MUST 保留预生成前缀全部公共来源及版本约束、中文和GBK字符转换、已声明图形/音频/输入能力、32/64位程序执行及维护入口的依赖闭包。删除通用开发和管理设施 MUST NOT 使游戏启动时重新联网安装它们。

#### Scenario: 全新配置与第二配置
- **WHEN** 基于精简环境准备两个新配置并启动中文及32/64位程序
- **THEN** 两份前缀均从预生成资产独立还原且无全量wineboot，中文显示和中文文件读取通过，运行能力不依赖被删除设施

#### Scenario: 软件图形与音频
- **WHEN** 使用已声明的llvmpipe或virgl及PulseAudio配置
- **THEN** 所需图形和音频库可实际加载并完成对应探针，不得因裁剪回退到未声明的替代方案

### Requirement: 有界安全删除与完整性

系统 MUST 将裁剪限制于私有候选树，拒绝根目录、路径穿越、链接逃逸、挂载越界及任何与保护项相交的删除；MUST 保留运行必需的链接闭包和许可信息，不得把许可证作为普通文档删除。

#### Scenario: 计划误删受保护字体
- **WHEN** 删除清单包含前缀清单引用的字体或运行文件
- **THEN** 裁剪失败且原始运行环境不变

#### Scenario: 恶意链接和PRoot实体
- **WHEN** 路径经符号链接越出候选树或模拟硬链接需要保留实体
- **THEN** 越界目标被拒绝且闭包中的必需实体不会被回收

### Requirement: 验证完成前不发布

系统 MUST 仅在候选身份、动态依赖、链接、实际locale和运行验收通过后发布精简环境；失败/取消 MUST 保留原共享环境和就绪身份。策略变化 MUST 使旧配方失效，不能标记旧完整环境已经精简。

#### Scenario: 发布前失败
- **WHEN** 裁剪后发生缺库、字体缺失、locale无效或任务取消
- **THEN** 候选不被发布，旧环境保持可用，错误可见且可重试

#### Scenario: 裁剪策略修订
- **WHEN** 新APK使用不同裁剪策略或配方
- **THEN** 新环境具有不同身份，只有显式准备成功后才显示就绪，不覆盖已有游戏C盘
