# 组件安装管理

## ADDED Requirements
### Requirement: 已安装组件由用户决定替换
系统 MUST 使用稳定组件ID及实际安装状态识别可用组件，不得按目录、配置或收据的修订号差异自动升级、替换或要求下载新版。
#### Scenario: 目录修订变化
- **WHEN** 已安装可用组件与目录记录的修订不同，用户保存游戏、构建环境或启动游戏
- **THEN** 继续使用该ID的已安装内容，不下载替换包、不重建prefix、不报修订不一致错误
#### Scenario: 组件实际缺失
- **WHEN** 用户保存/构建所需组件确实没有安装
- **THEN** 继续允许现有首次安装流程，不回退到另一个真实版本

### Requirement: 显式组件操作子菜单
系统 MUST 在现有版本列表为独立可安装组件提供操作子菜单，并将组件选择和安装管理分开。
#### Scenario: 已安装条目
- **WHEN** 用户打开已安装组件的操作子菜单
- **THEN** 可明确执行卸载或重装；点击条目仍用于选择，不偷偷重装
#### Scenario: 未安装条目
- **WHEN** 用户打开未安装组件的操作子菜单
- **THEN** 可明确执行安装，安装结果及时反映到列表
#### Scenario: 预装环境内容
- **WHEN** 列表显示RootFS内置Hangover
- **THEN** 标记其预装属性，不提供虚假的独立安装或卸载动作

### Requirement: 同版本重装使用明确来源
系统 MUST 对在线组件的显式重装重新获取当前目录来源，不能仅因版本或已完成任务相同而跳过。
#### Scenario: 同版本补包
- **WHEN** 发布包补齐文件但真实组件版本不变，用户执行重装
- **THEN** 使用新获取的包替换该组件，旧缓存不使其装回旧内容，其他组件和prefix保持
#### Scenario: 自定义重装
- **WHEN** 用户重装本地导入的组件
- **THEN** 选择本地来源并使用原组件ID覆盖安装；取消选择不修改安装
#### Scenario: 重装失败
- **WHEN** 下载、解包或安装失败
- **THEN** 立即以失败结束并展示原因，不自动切换组件、回退其他版本或重建prefix

### Requirement: 卸载状态真实且作用域明确
系统 MUST 清理所选组件的实际内容和全部安装就绪记录，停止相关任务和进程，不删除游戏、prefix或其他组件。
#### Scenario: 已安装组件卸载
- **WHEN** 用户执行卸载
- **THEN** 所选组件显示未安装，宿主与启动检查均不将其视为可用，所选ID不自动改变
#### Scenario: 卸载时任务仍存在
- **WHEN** 所选组件存在运行进程或尚未退出的安装/激活任务
- **THEN** 先强制停止相关工作，再串行清理，任务不能在卸载后自动发布回来
#### Scenario: 多版本共存
- **WHEN** 卸载或重装Box64 0.4.4
- **THEN** Box64 0.2.7、其他后端及游戏prefix不被误删或覆盖
