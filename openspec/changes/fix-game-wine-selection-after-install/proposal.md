# 修复安装Wine后未更新游戏选择

## 问题与目标
用户报告导入游戏后，从本地安装Wine，且已经手动装好Wine 10，保存后仍使用Wine 9.3。后续设备测试由用户手动完成，代理不得连接或操作设备。源码确认新建Native配置默认glibc_wine_9.3-vanilla；版本选择页的本地安装成功后只刷新列表，在线安装也未将安装目标返回游戏编辑器。只有点击已安装行才返回选择结果，因此安装操作后直接返回保存会保留旧值。

目标是在游戏版本选择上下文中，将用户本次请求安装的确切版本在安装成功且可用核验通过后返回编辑器，由保存流程持久化并使用该值。组件管理上下文只安装，不改变游戏。

## 范围与约束
覆盖本地归档、在线目录、已有已安装行选择，Native与PRoot隔离，兼顾选择页重建后本次安装目标的恢复。失败或产物未就绪明确报错，不返回成功选择，不自动选择9.3或其他版本，不自动重试，不添加wineboot、prefix重建或向前兼容。取消文件选择不会产生新版本选择。自定义Wine缺少预生成prefix资产时沿用明确失败要求，绝不伪装为目录Wine 10或替换成9.3。本修复不改变默认预设，不把安装了某版本等同于全局默认切换。
