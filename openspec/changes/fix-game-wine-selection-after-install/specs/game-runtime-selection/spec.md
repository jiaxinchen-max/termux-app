# 游戏运行时版本选择

## ADDED Requirements

### Requirement: 游戏选择上下文的安装必须完成对应版本选择
在游戏的组件版本选择页发起本地或在线安装后，只有本次目标安装成功并且可用性、种类、后端及既有翻译器约束核验通过，系统才应返回确切目标ID给游戏配置；保存及启动必须使用该ID。不得静默保留默认Wine作为本次新选择的结果。

#### Scenario: 本地安装后使用Wine 10
- **GIVEN** 新导入Native配置当前为Wine 9.3
- **WHEN** 用户在游戏Wine选择页从本地安装Wine 10且本次任务成功，目标可用
- **THEN** 编辑器显示本次安装Wine的确切标识，保存持久化该标识，准备和启动使用该标识
- **AND** 自定义Wine不得冒充官方目录Wine或通过其他版本兜底。

#### Scenario: 在线安装后使用所选目录版本
- **WHEN** 用户在游戏选择页安装目录Wine 10且本次任务成功、目标真实可用
- **THEN** 返回并保存glibc_wine_10.0，不能仍以glibc_wine_9.3-vanilla准备或启动。

#### Scenario: 安装未完成或失败
- **WHEN** 本次安装进行中、失败、取消、任务丢失或命令成功但目标不可用
- **THEN** 不返回成功选择，不宣称已选新版本；失败应明确可见，不选择其他Wine、不重试或重建。

#### Scenario: 管理模式安装
- **WHEN** 用户从独立组件管理页安装Wine
- **THEN** 仅安装组件，不改变任何游戏Wine配置。

#### Scenario: 选择页重建或重复刷新
- **WHEN** 本次安装过程中页面重建或多次刷新
- **THEN** 仅恢复同一任务对应目标，成功核验后最多返回一次，不启动新安装或应用历史任务。

#### Scenario: 直接选择已安装版本
- **WHEN** 用户点击已安装Wine 10
- **THEN** 返回精确版本ID并由保存/启动链路保留，拒绝跨后端或不符合已有翻译器约束的值。
