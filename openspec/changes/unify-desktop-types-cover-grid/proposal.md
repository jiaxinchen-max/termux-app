# 统一桌面类型与封面选择网格

## 背景与目标
用户发现 Native 仍提供独立 GNOME，要求 Native 与 PRoot 一致，仅支持 XFCE、Plasma、Ubuntu GNOME、Hyprland 四种桌面，并使用带封面和名称的卡片。最新反馈以 Wine 程序卡片的紧凑尺寸为参考，卡片宽度约为前版的 80%，不再要求固定两行两列。

变更前 DesktopDe.supportsNative() 仍允许 GNOME；supportsProot() 已排除 GNOME。DesktopCreateActivity 使用纵向 optionRow，Native 创建后隐藏对应候选，无法保持四个固定卡位。本变更统一支持矩阵与创建页呈现。

## 拟定范围
- Native 和 PRoot 的受支持类型均按 XFCE、Plasma、Ubuntu GNOME、Hyprland 排序；关闭独立 GNOME 的创建、保存、安装和启动支持。
- 创建页按可用宽度自动排列四种桌面，不固定列数；每张卡片使用各自的轻量本地封面，名称叠放在封面左下角，使用边框和勾选标记表达单选状态。
- Native 每类型仍最多一个实例；已创建类型保留卡片，显示“已创建”并禁用，默认选择第一个可创建项。全部已创建时禁用创建按钮。PRoot 四项仍可重复创建。
- 保留 Ubuntu GNOME 的 Shell、Mutter 及共享助手，不因取消独立 GNOME 类型而删除共享运行时。
- 不迁移、不自动转换、不自动删除旧数据；旧 GNOME 不可继续安装或启动，管理页仍须能显式删除旧记录。
- 所有初始化继续在保存／安装阶段完成，启动失败直接退出。
- 按用户追加截图要求，将桌面卡片安装时的圆环动画替换为从左向右单向扫过的横向光带，前端高亮、后方渐隐；保留封面和图标，颜色跟随主题，结束即停止。
- 四类封面卡片、扫描光带、状态文字、实体操作按钮和确认弹窗均支持深色／浅色主题。
- 桌面卡片左下角提供有明确填充背景的“启动”按钮，取代近似普通文本的 Open 样式；启动／进入桌面先确认名称及运行模式，确认后才进入会话页。卡片正文和封面不触发启动，安装和查看安装日志维持各自语义。
- 按用户对预览的反馈改为紧凑样式：封面压缩为小横幅、缩小主按钮外观、收紧卡片间距和内边距，保留足够触控范围、完整名称、深浅主题与二次确认。
- 名称放在封面上，使用底部渐变提高可读性，卡片正文不再重复名称；状态、参数和启动按钮仍保持清晰。
- 内容尺度参照 Wine 程序卡片，普通字号下桌面卡片参考宽度约 128dp、正文内边距约 6dp、标题 12sp、辅助文字 9sp、可见按钮高度约 28dp；不为填满一行放大卡片。
