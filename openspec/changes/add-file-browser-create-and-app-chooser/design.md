# 设计

## 当前实现及差异

GameFileManagerActivity 的工具栏包含刷新、视图模式及粘贴／取消／隐藏项菜单，尚无新建能力。BrowserFileOperations 已维护三个浏览根范围、链接检查及串行写操作所需边界；Activity.runFileOperation 在单线程 ioExecutor 中执行并刷新。openExternally 直接启动 BrowserDocumentsProvider.openIntent 返回的 ACTION_VIEW，因此已有默认应用会跳过应用选择。

## 工具栏与输入

在 local_game_browser_actions 菜单增加始终显示的加号“新建”图标按钮，不使用 withText，工具栏不显示文字，title 作为无障碍名称。复用 local_games_ic_add，不新增重复图标；展开“新建文件／新建文件夹”两项。横竖屏共用绑定，无需重复布局。沿用 FrostedDialogBuilder 和现有主题输入控件，仅要求名称，创建文件不填写正文。首页隐藏入口；目录中显示，导入或写操作期间禁用。即使按钮已禁用，回调仍检查运行状态，防止重复提交。

打开输入框时冻结目标目录与类型，确认后不因浏览位置变化改写到别处。校验名称不是空白、点号、双点号或路径；不得含分隔符及空字符。不静默修改用户名称，不添加扩展名，不递归创建名称中的目录。取消输入只关闭弹窗。错误保留明确反馈，用户可以修正或重新发起；共享存储继续使用既有存储权限流程。

## 文件创建边界和状态

BrowserFileOperations 新增创建方法，重新规范化并验证目标父目录在既有三根范围内且为现存目录，再构造直接子项。根目录本身允许作为父目录，原来源保护不变。拒绝同名文件、目录及悬空符号链接，不追踪已存在目标链接写入，不能复用会截断已有内容的 FileOutputStream。

空文件用独占 createNewFile，文件夹用 mkdir；返回失败必须检查并报告，不使用 mkdirs、不覆盖、不自动换路径或重试。Activity 通过现有 runFileOperation 串行执行，沿用进度、失败反馈和目录刷新；新建点号项目仍受当前隐藏偏好过滤，禁止因此自动改变显示设置。所有测试仅使用临时目录。

## 系统应用选择

openExternally 将原 ACTION_VIEW 包装为 Intent.createChooser 后启动。保留原 MIME、content URI、ClipData、临时只读标记，目录仍只授权所选子树，不授予写权限、持久权限或三个受保护根。使用系统选择器列出注册该文件类型的处理应用，不硬编码包名，不自建应用扫描，不新增 Manifest queries 或 Provider 接口。

即使系统默认应用存在，也始终启动 ACTION_CHOOSER；用户取消不调用具体处理应用。没有处理应用时允许系统选择器展示其空态，系统无法启动选择器时沿用无对应应用提示，不能回退直开、导入或游戏运行。文件短按继续显示现有详情和导入操作；只有明确的“打开”行为采用选择器。

## 系统边界、风险和回滚

Activity 负责交互和现有 IO 队列，BrowserFileOperations 负责创建范围与非覆盖规则，BrowserDocumentsProvider 保持只读与原路径验证。Service、shell、X11、输入、Wine、组件下载、备份和游戏库数据均无变化。无新增权限及受保护构建配置变更；无法读取保护策略源文件，记录其缺失，不声称完成策略门禁。

回滚仅撤销本方案的创建方法、菜单与文案、chooser 包装及增量测试；保留其他工作区修改。已创建的用户文件不自动删除。产品文档在用户验收前不作为已实现能力发布。

## 验证

先验证实际文件创建和不覆盖：空文件、目录、三个根作为父目录、非法名称、同名普通文件／目录／悬空链接、越界与失效父目录；确保失败前后原内容相同。

页面测试从实际工具栏进入，覆盖两个类型、确认与取消、首页与忙碌状态、创建后刷新、冻结目标路径、横竖屏。更新外部打开用例检查最外层 ACTION_CHOOSER 和内层 ACTION_VIEW 的 MIME、URI、ClipData 与只读授权，保留目录子树及 Provider 安全回归。适配“没有处理应用”的系统选择器空态／启动失败语义，不将启动 chooser 当成文件已经成功打开。

相关操作、页面、Provider 测试通过后构建正常 arm64 APK，文件名固定 `termux-app_apt-android-7-debug_arm64-v8a.apk`，核对原签名、无 testOnly 及资源。真实第三方应用选择由用户手动安装验收，不执行远程安装、设备操作、Git 操作或外部发布。
