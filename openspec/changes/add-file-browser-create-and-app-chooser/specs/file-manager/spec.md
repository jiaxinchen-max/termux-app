# 文件浏览器创建与应用选择

## ADDED Requirements

### Requirement: 工具栏支持创建文件和文件夹

文件浏览器必须在实际目录的工具栏提供仅显示加号图标的“新建”入口，不显示文字但保留无障碍名称。展开后用户可选择新建空文件或文件夹；首页三个入口列表中不提供该操作。

#### Scenario: 确认创建
- 当用户在目录内选择新建文件或文件夹，输入有效名称并确认
- 则在发起输入时的目标目录创建对应空文件或单层文件夹，成功后刷新列表。

#### Scenario: 取消或输入非法名称
- 当用户取消输入，或名称为空白、点号、双点号或包含路径分隔等非法字符
- 则不创建任何项目；非法名称必须明确提示，不能偷偷改名或添加扩展名。

#### Scenario: 冲突和范围检查
- 当目标同名项目或悬空链接已经存在，或目标父目录失效、越界、不可写
- 则明确失败，不覆盖、不合并、不换目录或自动重试，原文件和目录内容保持不变。

#### Scenario: 固定根内部创建及忙碌状态
- 当用户进入三个固定根目录之一
- 则允许在该根内部创建普通子项，根目录对象本身的保护仍保留。
- 当导入或文件写任务正在执行
- 则禁用新建并在执行回调再次拒绝重复提交，写操作继续串行。

#### Scenario: 创建隐藏项
- 当用户创建以点号开头的合法名称
- 则按原隐藏项偏好决定是否显示，不自动改变该偏好。

## MODIFIED Requirements

### Requirement: 系统文件打开方式

“打开”必须每次先显示 Android 系统应用选择器，用户选择注册该 MIME 类型的处理应用后才打开；此规则替代先前遵循系统默认应用直接打开的规划。

#### Scenario: 已有默认处理应用
- 当用户对文件或非根目录执行“打开”，即使系统已有默认应用
- 则启动 ACTION_CHOOSER，其目标为携带准确 MIME、content URI、ClipData 和临时只读权限的 ACTION_VIEW，不直接启动默认应用。

#### Scenario: 取消或没有对应应用
- 当用户取消应用选择
- 则不执行具体文件打开动作。
- 当没有对应处理应用或选择器无法启动
- 则展示系统无可用应用状态或明确的启动失败提示，不回退为直接打开、导入或游戏运行。

#### Scenario: 访问边界及既有导航
- 当用户选择处理应用
- 则只临时授权所选文件或目录子树的只读访问，不扩大为根目录或写权限。
- 当用户短按文件、短按目录或长按空白
- 则分别保留现有文件详情、目录导航及无空白菜单行为。
