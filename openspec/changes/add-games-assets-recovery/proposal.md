# Proposal: Games assets, recovery and safe uninstall

## Why

游戏详情目前只能删除库记录，用户无法解释 prefix、缓存、日志和恢复点的占用，也无法在运行配置或 prefix 损坏后回滚。删除能力必须明确区分 app 私有数据与 SAF 外部游戏目录。

## What changes

- 增加按游戏聚合的私有资产分类和递归占用统计。
- 增加配置与 prefix 的原子快照、摘要校验、回滚和删除。
- 增加安全卸载计划，默认仅删除库记录；私有 prefix、缓存、日志、快照和配置必须显式选择。
- 增加游戏资产与恢复页面，并从游戏详情进入。
- 保持外部游戏目录、外部存档和 SAF 内容只读且永不进入删除计划。

## Non-goals

- 不扫描或备份外部 SAF 游戏本体。
- 不实现云存档或任意用户目录备份。
- 不在游戏运行任务活跃时修改 prefix、快照或卸载私有资产。
