# 补齐Native Box64运行库

## 问题与确认
已通过真实设备启动日志确认：Native Box64 0.4.4加载Proton11 ntdll.so时缺少x86-64 libgcc_s.so.1，退出码1。真实归档检查确认0.4.4包仅含Box64二进制，旧默认包含7个x86-64配套库，PRoot版本的库属于独立包。用户在解释打包、依赖安装与搜索路径缺口后明确要求“这肯定是给他打包是漏了呀，补上”，授权补齐已讨论范围。

## 范围
复用旧Native包的7个x86-64配套库，生成完整0.4.4新版本资产；保留原Box64二进制及版本并存目录。启动搜索路径加入所选Box64组件的lib/x86_64-linux-gnu。更新组件目录版本和新资产信息，使新保存/安装可取得完整包。APK名称不变，不重建prefix，不回退版本，不引入整套系统或无关库。
