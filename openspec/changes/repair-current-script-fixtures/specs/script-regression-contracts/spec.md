# 脚本回归契约

## Purpose

为维护者提供可以在本地临时隔离环境执行的脚本回归入口，验证当前 Wine 启动、控制器、用户环境变量优先级及桌面音频和会话清理的现有契约。回归结果必须区分夹具正确执行、行为错误及环境条件缺失，避免沿用过时夹具产生的失败或误报成功。

## ADDED Requirements

### Requirement: 当前启动规格可被有效回归

Native 与 RootFS 启动回归 MUST 使用当前启动器接受的规格及所需局部依赖，并执行真实被测脚本；参数、错误、取消和清理断言 MUST 保留。

#### Scenario: 当前版本启动夹具执行

- **WHEN** 维护者在具备标准 shell/Python 工具的 Linux 环境运行两个启动回归脚本
- **THEN** 有效规格必须到达启动行为断言，并正确保留空格、引号、反斜杠和美元符号参数
- **AND** 无效前置条件必须明确失败，取消或退出必须核对任务拥有资源的清理

### Requirement: 控制器与环境变量回归保持故障敏感

控制器与环境优先级测试 MUST 验证当前真实脚本的导出及调用行为；被测逻辑损坏时 MUST 非零退出，不能仅因找到字符串或补齐 mock 就报告通过。

#### Scenario: 用户环境与调试预设同时存在

- **WHEN** 用户变量包含空格、引号或与调试预设重名
- **THEN** 回归必须验证用户值保持，未配置项继续使用对应预设

#### Scenario: 手柄 Libraries 配置变化

- **WHEN** 对不同 mapper 配置 DLL 加载顺序，或完全不配置覆盖值
- **THEN** 回归必须验证已配置手柄的实际导出值、未配置手柄时对应覆盖项为空，以及显式 Direct3D 基线独立保留；同时保留架构和重复安装的校验

### Requirement: 桌面音频前置条件必须显式

桌面回归 MUST 提供当前显式音频模式与局部服务地址，并验证缺失/非法模式和服务失败；不得依赖宿主真实 PulseAudio 或隐式默认值。

#### Scenario: 正常音频条件下切换桌面

- **WHEN** GNOME 或托管桌面夹具提供有效音频配置
- **THEN** 回归必须执行到原有桌面生命周期断言，并验证旧会话清理完成后才启动新会话

#### Scenario: 音频配置缺失或服务失败

- **WHEN** 显式音频模式缺失、非法，或局部音频服务不可用
- **THEN** 回归必须观察到明确的失败结果，且不能报告新桌面成功启动

### Requirement: 测试证据与现场资源隔离

六项脚本 MUST 在临时隔离目录执行，仅清理其拥有的进程与文件；结果 MUST 保留命令、退出码及日志，并与设备/构建结果分开表达。

#### Scenario: 保存本次组合回归结果

- **WHEN** 六项脚本组合执行完成
- **THEN** 每项通过、失败或环境限制必须可独立核查
- **AND** 脚本通过不得改变真实 USB、GPU、PRoot Plasma Stop 和完整设备矩阵的待验证状态
