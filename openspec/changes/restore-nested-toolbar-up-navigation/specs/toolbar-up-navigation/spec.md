# 工具栏上一级导航

## ADDED Requirements

### Requirement: 设置子菜单提供逐级返回按钮

设置的每个非根页面必须在工具栏左侧显示返回上一级图标，点击后只返回当前页面的直接父级。设置根页没有上一级图标。

#### Scenario: 从后端设置返回

- **WHEN** 用户在设置的 Native 或 PRoot 子页点击工具栏返回箭头
- **THEN** 显示 Core components 页面且仍显示返回箭头
- **AND** 再次点击后显示设置根页并隐藏该箭头

#### Scenario: 已有子页入口

- **WHEN** 用户进入已有组件版本页或运行抽屉的控制器子页
- **THEN** 现有上一级按钮和逐级返回行为继续可用

### Requirement: 文件浏览器提供有边界的上一级按钮

浏览实际目录时必须在工具栏显示上一级图标。普通子目录返回直接父目录；程序文件、应用私有文件和共享存储各自的根目录返回三个入口列表，不能跳到该根目录外。入口列表不显示上一级图标。

#### Scenario: 逐级返回入口列表

- **WHEN** 用户从任意入口进入根目录及其多层子目录，连续点击工具栏返回箭头
- **THEN** 每次只返回一个目录层级
- **AND** 在所属根目录点击时显示三个入口列表并隐藏箭头

#### Scenario: 保留文件操作

- **WHEN** 用户在浏览器切换目录、视图模式或隐藏文件显示状态
- **THEN** 上一级按钮与当前目录同步
- **AND** 既有新建、复制、剪切、粘贴、删除及打开操作保留

### Requirement: 导航按钮适应页面状态和显示配置

返回按钮必须使用图标和上一级无障碍描述，适配当前主题。横竖屏变化或页面恢复后，按钮可见性和返回目标必须符合恢复后的页面层级。

#### Scenario: 恢复深层页面

- **WHEN** 页面在设置子页或实际目录内旋转或恢复
- **THEN** 返回箭头仍可见且点击后返回当前层级的直接上一级
- **AND** 深色和浅色模式下图标清晰可见
