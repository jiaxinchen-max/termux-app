# 更新 X11 桥接包及依赖安装

用户明确要求：xkeyboard-config 作为 termux-x11-nightly 的非固定版本依赖，从仓库安装最新候选版本；删除APK内嵌的键盘配置deb；安装桥接包前更新索引；强制重装，支持降级；生成脚本及产物版本升为1.04.10-0。此明确指令作为本次范围确认与实施授权。

当前生成脚本已包含无版本约束的依赖声明，但安装脚本直接dpkg安装内嵌键盘包，且先删除桥接包、没有失败即停。根目录install与APK资产不同，重新打包会覆盖已有修正。终端手动重建和程序模式首次补齐都有固定资产文件名，需同步更新。

采用统一的安装脚本：先apt-get update，再以--reinstall和--allow-downgrades安装本地桥接deb及仓库候选键盘配置；缺少X11软件源时自动安装x11-repo并刷新索引。任何安装或更新命令失败立即返回错误。权限由生成的deb设置，不再以最后一个chmod掩盖安装失败。程序模式需等待安装进程自然结束，避免新增网络步骤被原有两分钟超时中断。不增加按版本自动升级和兼容迁移。

HTTP契约未改变，api_docs为N/A。产品可见依赖安装方式改变，product_docs为Required，目标docs/product/terminal-x11.md；最终用户验收前保持一致性Pending。正常APK保持原名、原签名及非testOnly；用户手动安装并验收，不操作设备或发布远程资产。
