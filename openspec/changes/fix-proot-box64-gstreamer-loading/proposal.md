# 修复 PRoot Box64 的 GStreamer 加载

## 问题与已确认范围

用户要求继续排查此前排除的 GStreamer 媒体问题，先查询互联网；在展示上游 Box64 PR #4528 的错误 GTK 依赖及回移方向后，用户明确批准。随后用户强调组件必须在已有编译机编译，复用其环境、补丁、往期存档与上下文。本次只确认并修复当前默认 PRoot Box64 0.4.4 的相关加载问题，不假定它可以消除全部 Wine 媒体失败。
