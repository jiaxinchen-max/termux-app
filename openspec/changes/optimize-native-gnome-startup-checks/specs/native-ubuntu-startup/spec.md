# 原生 Ubuntu GNOME 初始化与启动

## 要求：静态检查不在日常启动执行

原生 Ubuntu GNOME 日常启动应直接执行会话，禁止调用完整主题校验、依赖版本/导入探测、初始化缓存比对或因组件变动而自动扫描。启动只加载必要配置，并保留参数约束和当前会话的实际运行结果检查。

场景：已安装桌面启动，不扫描主题清单，不进行版本/导入预探测，不创建或比对初始化缓存。
场景：实际运行报错或进程退出，按现有失败处理结束，不隐藏错误或自动回退。

## 要求：安装与显式诊断完成检查

安装开始清除安装成功标记；归档校验、主题提取后完整校验、依赖运行探测全部成功后，才记录安装完成。

场景：安装中任何校验或依赖探测失败，不留下安装成功标记。
场景：用户显式调用诊断命令，仍执行完整主题校验及依赖探测。

PRoot 行为与单次 D-Bus 查询超时策略不在本轮修改范围。
