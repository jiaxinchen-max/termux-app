# Desktop 卡片展示边界

## ADDED Requirements

### Requirement: 管理卡片有界展示
Native与PRoot管理网格必须保持128×160dp，封面52dp。名称最多两行，模式角标、安装扫描条、正文、单行状态和48dp操作区不得互相遮挡。长文字尾部省略，保留完整数据。列表保持全宽，操作列不得随长按钮标签无限扩宽，长名称和参数单行省略。

#### Scenario: 长内容和大字体
- 当窗口宽度或系统字体改变，卡片展示长中文或英文名称、组件参数、安装或错误状态
- 则网格高度不变，文字受限，操作区保留，列表正文仍有可用空间。

### Requirement: 新增导入和创建卡片的文字与图片有界
新增／导入标签必须限制行数并省略超长部分。创建页在同一字体和卡宽下应保持一致的两行标题区域；可以随字体整体增高，不随单个标题长度增高。已创建与选中标记不得重叠；完整标题保留在文本和无障碍描述中。
所有封面必须在分配区域内等比例完整缩放，不裁切、不拉伸，不由图片原尺寸推动卡片或操作区域。

#### Scenario: 封面或标题替换
- 当短名称替换为超长名称，或封面替换为宽图、长图、方图
- 则同一字体下卡片几何边界不变，超长文字省略，图片等比例位于封面内。
