# 游戏库卡片展示增量规范

## ADDED Requirements

### Requirement: 同一网格使用统一卡片边界
系统必须对 Native／PRoot 游戏网格和导入项使用统一的 180dp 卡高与 56dp 封面高度。卡宽遵循同一窗口下既有列数规则，卡片不得因文字长度、图片尺寸或加载时序改变大小。

#### Scenario: 长短 Wine 名称相邻
- **WHEN** 同排卡片分别展示 `Wine: wine_10.0` 和 `Wine: rootfs_hangover_11.16` 或更长的自定义名称
- **THEN** 卡片上下边界和底部操作对齐，长字段尾部省略，不撑高卡片。

#### Scenario: 导入项与窗口变化
- **WHEN** 游戏数量、横竖屏或窗口宽度变化，导入项位于同行、下一行或空库
- **THEN** 导入项与游戏卡片使用同一卡高，保留现有换行和顺序规则。

### Requirement: 文本省略只影响展示
网格名称、Wine 和状态最多一行，可执行文件固定两行，超出空间尾部省略。放大字体时保持卡片边界和底部操作可用，完整数据不被改写。列表 Wine 文本同样最多一行，不改变列表全宽布局。

#### Scenario: 长中文、错误状态与放大字体
- **WHEN** 名称、EXE、Wine 或错误文案超出区域，或字体放大
- **THEN** 使用文本控件省略和有界布局，详情／更多仍处于卡片内部；已保存名称、路径及 Wine 身份不变。

### Requirement: 图片在固定区域等比例完整缩放
封面必须在固定边界内等比例缩放，不拉伸、不裁切；默认图与异步加载图片均不得参与扩大卡片尺寸。

#### Scenario: 不同比例图片及异步替换
- **WHEN** 加载宽图、长图、方图或将默认图替换成真实图片
- **THEN** 图片完整显示且比例保持，卡片和按钮位置不变。

### Requirement: 保留交互和运行语义
展示修复必须保留现有安装中动画、启动与恢复会话、详情、更多菜单、后端筛选和深浅主题，不更改容器数据或运行流程。

#### Scenario: 两种后端与两种展示方式
- **WHEN** 切换 Native／PRoot 或网格／列表并使用已有操作
- **THEN** 使用正确的游戏与 Wine 身份，现有操作语义保持一致。
