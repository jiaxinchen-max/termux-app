# 桌面会话交互增量规范

## 新增要求：退出确认
桌面会话的退出入口必须显示取消和确认两个操作，并提示停止会话和未保存内容风险。不得提供仅关闭视图操作。取消必须保持会话与显示；确认必须只提交一次当前桌面停止任务。仅在停止成功、会话不再活跃后返回列表；失败必须可见且允许重试。

场景：用户在普通或紧凑抽屉、X11退出请求、启动等待页触发退出，均进入同一确认流程。取消后可继续操作，确认后列表显示桌面已停止，能够重新打开。停止异常不得被当作成功退出。

## 新增要求：去除悬浮菜单
桌面运行界面不得有三横线悬浮按钮，关闭抽屉、旋转及Activity重建不得重新出现。Android返回键及现有控制中心请求仍可开关或打开控制抽屉，抽屉功能继续可用。

场景：原生和容器桌面进入后无悬浮按钮，返回键打开抽屉，再按返回键关闭抽屉，画面无新增悬浮控件。

## 新增要求：新增桌面保存后自动安装
新增原生或容器桌面保存成功后必须立即提交该桌面安装并显示既有安装控制台，不得要求用户再次点击安装或确认安装。不得因刷新、旋转、重复点击或结果重放重复提交。安装完成不自动启动桌面。

场景：选择桌面并点击保存，记录成功落盘后自动进入安装；取消创建或保存失败时不安装。保存失败显示错误并保留输入。安装启动或执行失败保留记录，显示失败并允许通过列表重试；重试沿用已有安装约束和成功标记。
