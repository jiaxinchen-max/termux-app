# 容器 Plasma 启动设计

## Context

动机及调查限制见 proposal.md。部署脚本与 497bd9da 一致；未复现 Dolphin 的旧 UPower 超时。当前音频助手已检查 TCP 与 Android sink，所以端点后来消失仍需捕获服务退出证据，不能声称已经找到退出根因。正式 openspec/specs 和 docs/product 当前不存在，相关活动规划已读取。

## Goals / Non-Goals

优化 PRoot Plasma 的真实启动路径与状态一致性，保留安装校验和显式失败；不通过减少日志、静音、自动换渲染器获得表面提速。不新增跨总线代理或放宽身份认证，不把 org.kde.KWin 缺失解释为已证实的长超时。

## Decisions

### 安装构建缓存

在 desktop_install.sh 的 initialize_desktop 完成边界或对应容器助手中，以正式会话相同 HOME、XDG_DATA_DIRS/XDG_MENU_PREFIX 构建 KDE 服务缓存，先构建成功再写安装成功。初装、显式重新初始化及 App 管理的包变更均覆盖；用户自行在容器更新包沿用发行版缓存机制，必要时显式重新初始化。正常启动移除全量构建，不增加目录扫描、版本比对或自动补建。已有测试容器在设备验证时显式初始化，不做旧数据迁移。

### 有限服务等待

保留 PolicyKit 就绪后启动 PackageKit。将秒级固定休眠改为短间隔、以单调时钟总期限约束的就绪等待，每次调用自身也受剩余期限约束。确认安装版本 kactivitymanagerd/kded6 的实际总线名称与常驻行为，依赖独立才同时启动并收集就绪结果。保留退出码、必需服务监督及会话归属清理；不能单凭 kill -0 宣告服务就绪。缺少可验证的就绪接口时保留安全串行行为并报告限制，不删除必要服务。

### 容器就绪与耗时

宿主启动器生成本轮会话标识，清旧 marker，将标识传入容器；容器在必要服务与 plasmashell 实际会话接口可响应后原子写入带标识的 marker。DesktopTasks 的 PRoot Plasma 分支同时检查本轮 compositor、容器监督进程存活与匹配 marker；退出/停止/删除均清理 marker，超时记录失败并只清理本轮会话。原生 Plasma 保留原判据。

阶段计时记录合成器、总线、授权服务、KDE 服务及 shell 响应，使用同一单调时间基准；禁止为了计时运行重型 strace。服务响应就绪不称为已绘制首帧，面板/图标与 Dolphin 窗口的实际出现通过带时间戳的设备观测单独记录。

### 音频生命周期

首先对照启动日志和服务退出证据定位端点消失阶段，审查本轮会话及共享启动/停止路径，复现后修复具体归属或生命周期问题。为现有 pactl 请求提供有界等待，并在容器就绪前再次确认真实端点及 Android sink；运行中用低频、有期限的健康监督发现服务丢失，明确记录音频故障并撤销可用状态、结束受影响会话，不无限重启、不静音继续。共享健康 PulseAudio 不随任一桌面停止而被杀，保留已替换可执行文件仍健康的服务复用。若暂不能复现退出原因，只交付有证据的优化及故障诊断，不声明音频根因已修复。

PipeWire/蓝牙等错误先分类；本轮不批量禁用模块，不隐藏日志。需要新增功能策略或 KWin 代理时另行规划。

### 模块与权限边界

Activity 继续展示现有任务状态，不新增技术参数交互；TermuxService 启动通道保持。shell 管理容器和实际服务，Java 读取会话证据。X11 桥、Wayland 渲染组合、输入路由、用户存储和组件下载格式不变。共享音频助手变更覆盖 GNOME/XFCE/Hyprland 回归；若需要额外桌面行为变化，先更新规划。

仓库无保护路径策略及 policy id，不能虚构。预期只动应用 Java、脚本、初始化助手和测试，不动 manifest 权限、签名、原生实现、CI、组件配方或总线策略；若实际定位必须触及高风险路径，记录影响/回滚/验证并先获得专项批准。

## Risks / Trade-offs

- 依赖竞态：用实际接口验证，必要服务失败测试必须保留；无法证明独立时不并行。
- 陈旧 marker：会话标识与宿主/容器进程匹配，停止和异常路径删除，失败不得残留 RUNNING。
- 缓存用户不一致：初始化与正式会话使用相同用户和 XDG 环境；覆盖初装及重新初始化失败。
- 共享音频误伤：仅管理自有监督进程，不终止健康共享服务；有音频失败时显式退出比无声继续更明显，需用户确认此方案。
- 性能波动：同配置至少三次前后对比，分别报告冷/热服务状态、服务响应和首帧，不能与旧进程时间混算；不承诺未经实测的固定秒数。

## Migration Plan

无旧配置迁移。方案确认后实现、审查及本地验证；设备安装/重启桌面验证需明确部署授权。构建 APK 时保持既定名称及可正常安装属性，但本轮不默认发布。回滚应用脚本与 Java 就绪读取，显式重新初始化缓存；保留用户容器数据与共享音频服务。产品文档 docs/product/desktops.md 在最终验收后更新。
