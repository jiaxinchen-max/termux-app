# 容器 Plasma 启动优化任务

## 1. 确认与测量

- [x] 1.1 获取用户对本 proposal/design/specs/tasks 的确认并记入运行记录；完成条件：确认范围及任何高风险路径专项批准有明确记录。
- [ ] 1.2 实现前补齐同配置的阶段计时及音频退出证据；完成条件：基线记录区分进程、服务响应、首帧与 Dolphin 窗口，至少三次设备对比的执行需取得部署/重启授权。

## 2. 缓存初始化与服务等待

- [x] 2.1 将全量 KDE 缓存构建移入同用户/XDG 环境的安装与重新初始化完成边界；完成条件：执行型测试证明构建失败不写安装成功，正常启动不调用全量构建或扫描。
- [x] 2.2 替换固定休眠为真实服务的有限等待，核实 kded6/kactivitymanagerd 依赖后调整并发；完成条件：聚焦测试覆盖快速就绪、依赖顺序、立即退出和超时，耗时不叠加无界子调用。

## 3. 容器就绪与清理

- [x] 3.1 实现本轮会话绑定的原子就绪证据与 Java 读取，记录阶段耗时；完成条件：测试证明裸 KWin、旧 marker、容器退出均不判为可用，正常服务响应才就绪，日志不冒称首帧。
- [x] 3.2 完善停止、删除、超时与异常的证据清理；完成条件：失败注入和停止后重启测试无陈旧就绪、无裸合成器残留，不清理其他会话进程。

## 4. 音频生命周期

- [ ] 4.1 根据退出证据修复已确认的音频生命周期缺陷；完成条件：复现用例前后对照及根因记录齐全，无法复现则明确标为未解决，不以猜测声明修复。
- [x] 4.2 为音频操作及健康监督增加有限失败处理；完成条件：执行型测试覆盖拒绝连接、无响应、缺少 Android sink、运行中丢失服务，且健康共享服务与 deleted-exe 复用仍通过。
- [x] 4.3 更新开发验证记录并核查共享影响；完成条件：现有音频、初始化、渲染组合和相关会话状态回归通过，GNOME/XFCE/Hyprland 未验证设备项单列限制。

## 5. 集成验证与评审

- [x] 5.1 完成变更审查、语法/相关单测及本地构建检查；完成条件：无未解决 MUST_FIX，逐项记录真实结果，缺少工具不记为通过。
- [ ] 5.2 在明确设备验证授权后，按同配置完成至少三次前后启动与 Dolphin 首窗测量及实际音频播放；完成条件：报告每次耗时、冷/热状态、服务健康、窗口可交互证据与性能差异，失败如实保留。
- [x] 5.3 运行可用的 OpenSpec 严格校验及 Harness strict-run；完成条件：前者通过，后者缺失则保持 Unavailable 并报告，不能伪造完整流程通过。

## Workflow follow-up

- 用户最终验收后更新 docs/product/desktops.md 并完成知识一致性审查；归档另行遵循授权流程。
- 暂存、提交、推送、发布及设备安装需要相应明确授权，本规划不替代这些授权。
