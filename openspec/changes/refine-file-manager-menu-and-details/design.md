# 设计

## 当前实现证据

`termux-ui/src/main/java/com/termux/ui/activity/GameFileManagerActivity.java` 的 `showFileMenu` 无条件添加 `target.getName()` 禁用行，并为任何非目录文件添加 IMPORT。`showFileDetails` 只把 `looksLikePortableExecutable` 的结果用于提示文案，导入按钮和 C: 盘提示始终添加。

`PeExecutableInspector.isPortableExecutable` 当前只检查有界 DOS 头及 PE 签名，不能区分 EXE、DLL 或驱动。背景来自共享 `local_games_dialog_surface`：亮色 alpha 为 `0x8C`，暗色为 `0x94`；`FrostedDialogBuilder.create` 固定使用共享背景。

既有 `GameFileManagerOperationsTest`、`GameFileManagerBlankSpaceTest` 明确断言菜单首行是文件名、文本文件也有导入。实施时应改为验证新交互，不能为保留错误测试而保留错误行为。

## 一、文件内容识别及导入入口

在现有检查器中提供明确的 Windows 程序判断，保留旧的通用 PE 签名检查语义，避免扩大既有调用的兼容变化。新判断有界读取 DOS／PE／COFF 和必要的可选头：支持 PE32／PE32+，要求可执行映像、排除 DLL，且子系统为 Windows GUI 或控制台，以排除驱动／EFI 等非应用。按内容判断，不使用 `.exe` 名称白名单，也不在这里推断具体 Wine 后端能否运行某个 CPU 架构程序。

不存在、目录、无法读取、头部截断、偏移越界或无效结构统一视为不可导入；不为普通文件弹出检测错误。对两类入口复用同一判定，不建立按名称或路径永久缓存。

识别在后台执行，有界读取避免把大文件整体载入内存。回调绑定文件及当前界面请求，销毁页面、退出目标菜单／弹窗、目录变化或新请求覆盖后不得把旧结果用于其他文件。检测完成前不显示导入；忙碌状态仍遵守已有导入／写操作互斥。

详情先展示只读文件信息。识别成功后提供原有 Native／PRoot 标签的导入动作与 C: 盘提示；识别失败则只有文件信息和关闭动作。长按菜单同样仅在识别成功时添加导入。用户实际点击导入后，在后台、创建草稿之前重新检查目标，防止菜单展示后目标被替换为普通文件仍生成配置；失败时明确提示，不能创建半条草稿。该检查限定本浏览器入口，不改变其他导入入口的业务规则。

## 二、菜单与详情内容

移除条目菜单禁用名称行，不以另一个标题或路径代替。操作仍针对捕获的目标对象；固定根保护、空白长按无菜单、多选、单项复制／剪切／删除及外部打开逻辑继续复用。

单击文件在普通模式下只打开详情，不自动导入、启动程序或调用系统应用。文件名保留于详情标题，基本信息为大小及修改时间；普通文件移除 Windows 相关判断句和 C: 盘建议。有效程序仅在详情内显示导入动作，导入后仍进入现有配置草稿编辑流程。

## 三、降低文件管理器弹层透明度（视觉方案已由后续变更替代）

2026-11-18用户批准 `unify-termux-ui-dialog-opacity`，替代最初局部90%设计：亮色 `#D9FCF7F0`、暗色 `#D9201813`，统一85%不透明。条目 PopupMenu 保留局部主题与padding，但填色引用公共对话框颜色；详情和确认／错误／输入对话框直接使用共享builder背景，继续保留现有尺寸、模糊和遮罩规则。

只调整背景填充 alpha，不设置整个 View／Window 的透明度，不使文字及图标变淡。背景在 API 31 以下、系统模糊关闭或模拟器未提供模糊时也应可读；不以模糊实际生效作为可读性前提。按后续已批准需求，公共 `local_games_dialog_surface` 统一负责所有模块弹窗的填色。

## 验证

针对识别器使用真实结构的最小 PE32／PE32+ 测试样本，覆盖有效程序、内容有效但无 `.exe` 后缀、伪装 `.exe`、DLL、驱动、文本、归档及损坏／截断／越界头。UI 测试验证详情与菜单同时隐藏或显示导入，普通文件无 Wine 提示，点击详情不产生导入草稿，多选仍只选中，原文件操作和空白长按回归通过。覆盖有效 Native／PRoot 导入标签及失效目标的提交前拒绝。

视觉验证覆盖亮／暗、横／竖屏及无模糊环境的菜单与详情可读性；无法设备实测时如实记录限制。复用相关回归，不为颜色数值本身增加机械测试。严格脚本缺失时记录 Unavailable，不当作通过。

## 风险与回滚

主要风险为过严内容检测误隐藏合法程序、异步结果串到另一个条目、局部主题被共享 builder 背景覆盖。分别通过 PE32／PE32+ 样本、请求生命周期约束及背景实际应用核对控制。未发现保护路径注册表或 policy id，不推断额外审批。

本轮不迁移持久化数据，回滚相应 Activity、识别器和局部资源即可；原导入配置及文件内容不变。七个 native 子模块现存修改不属于本轮。
