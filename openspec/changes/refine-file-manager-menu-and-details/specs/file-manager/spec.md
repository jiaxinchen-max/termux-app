# 文件管理器菜单与详情

## MODIFIED Requirements

### Requirement: 条目菜单仅展示有效操作

条目菜单 MUST 直接展示可执行操作，MUST NOT 添加文件名、目录名或路径作为占位标题行。文件及普通目录的打开、复制、剪切、删除和多选继续可用；导入仅适用于已识别的 Windows 程序。固定根目录对象及长按空白的保护保持有效。

#### Scenario: 长名称普通文件及目录
- **WHEN** 用户在普通模式长按长名称文件或普通目录
- **THEN** 菜单从操作项开始，不重复名称，菜单操作仍针对该条目；普通文件及目录均无 Wine 导入。

#### Scenario: 可执行程序的菜单
- **WHEN** 用户长按经内容识别有效的 Windows 程序
- **THEN** 提供当前所选 Native／PRoot 后端的 Wine 导入动作，普通操作仍然存在。

### Requirement: 单击文件显示信息并按内容提供导入

普通模式单击文件 MUST 展示文件名、大小及修改时间，MUST NOT 自动打开系统应用、创建导入草稿或运行文件。仅有效的 Windows GUI／控制台 PE 可执行程序可显示 Wine 导入与相关提示；普通文件仅显示文件信息及关闭动作。目录点击及多选点击维持原语义。

#### Scenario: 普通归档、文本及伪装文件
- **WHEN** 用户单击 `.archive`、文本、无效 `.exe`、DLL、驱动、损坏或无法识别的文件
- **THEN** 详情只有文件信息和关闭动作，无 Wine 导入按钮、C: 盘提示及 Windows 类型判断提示。

#### Scenario: 有效 PE32 和 PE32+ 程序
- **WHEN** 用户单击结构有效的 Windows GUI／控制台 PE32 或 PE32+ 程序，含未以 `.exe` 命名的程序
- **THEN** 除基本信息外显示后端对应的 Wine 导入按钮和相关提示，只有主动点击按钮才进入原有草稿流程。

#### Scenario: 异步检测与目标变化
- **WHEN** 检测尚未完成、用户切换目标／目录、页面销毁，或导入前文件被替换为非程序
- **THEN** 未完成或失效结果不提供导入、不影响其他目标；导入提交前再次验证，失败不创建配置草稿。

#### Scenario: 目录导航与多选
- **WHEN** 用户点击目录或在多选模式点击文件
- **THEN** 分别导航至目录或切换选择状态，不弹出文件详情，不自动导入。

## ADDED Requirements

### Requirement: 文件管理器弹层背景保持可读

文件管理器条目菜单与对话框 MUST 共用模块85%不透明的背景填充，保持亮／暗主题配色、文字图标清晰及现有圆角／描边。MUST 在无系统模糊时也保持内容可读，MUST NOT 通过整体透明度淡化文字。本条已由2026-11-18用户批准的 `unify-termux-ui-dialog-opacity` 同步，替代原局部90%及限定不影响其他页面的视觉方案。

#### Scenario: 文件列表上展示菜单和详情
- **WHEN** 在亮色或暗色、横屏或竖屏、支持或不支持系统模糊的环境打开文件管理器菜单及详情
- **THEN** 底层文件列表对前景文字的干扰降低，操作项和文件信息清晰，关闭及原有交互仍然有效。
