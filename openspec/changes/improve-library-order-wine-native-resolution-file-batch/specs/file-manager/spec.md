# 文件浏览批量操作

## ADDED Requirements

### Requirement: 网格和列表共享多选状态

App 文件浏览器 MUST 在实际目录提供多选入口、可见勾选、已选数量、全选／取消全选和退出选择；两个布局使用同一组选择。MUST 保留普通文件详情、目录导航、原单项菜单及长按空白无操作的行为。首页三个固定根入口 MUST NOT 被选择为操作对象。

#### Scenario: 进入选择并执行全选
- **WHEN** 用户通过工具栏或项目菜单进入多选并全选
- **THEN** 仅选择当前目录可见且允许操作的项目，包含文件及普通子目录，批量动作只在有有效选择时启用。

#### Scenario: 刷新、布局切换与返回
- **WHEN** 用户切换网格／列表、旋转屏幕、修改隐藏项可见性、外部文件被删除或按返回
- **THEN** 合法且仍可见的选择保留，失效项剔除；返回先退出多选，切换目录后不残留上一目录选择。

### Requirement: 批量复制和剪切支持跨目录粘贴

系统 MUST 对选择快照创建多项剪贴板，进入目标目录后串行粘贴。MUST 先预检所有项目的作用范围、权限、同名、源目标相同及自身子树；冲突 MUST NOT 导致覆盖、合并或自动改名。剪切 MUST 等到单项目标完整发布后才删除该源。

#### Scenario: 混合文件和文件夹跨目录粘贴
- **WHEN** 用户复制或剪切多个文件／目录，进入另一个允许访问目录粘贴
- **THEN** 整批串行执行且目录内容完整，复制保留源，完全成功的剪切从剪贴板移除，列表完成后刷新。

#### Scenario: 预检冲突与执行期间错误
- **WHEN** 预检发现任一冲突，或执行中某项首次失败
- **THEN** 预检冲突不开始写入；执行错误立即停止后续项目，区分完全完成、失败及未执行，不声称整批原子回滚。

#### Scenario: 剪切目标已发布但源删除失败
- **WHEN** 目标完整发布后源删除失败
- **THEN** 报告源及目标和部分移动情况，不直接把该项当作尚未执行自动重试，未尝试项目可保留。

### Requirement: 批量删除明确确认并报告结果

删除 MUST 先显示选择数量及可查看的名称列表，取得用户确认后才执行。MUST 复用固定根保护、作用范围及不跟随符号链接递归规则；权限与底层检查不能只依赖界面勾选。

#### Scenario: 取消与部分失败
- **WHEN** 用户取消删除，或某项执行失败
- **THEN** 取消不修改任何文件；失败后停止，明确已完成和未执行项目，不显示整批成功。

#### Scenario: 符号链接、共享存储和忙碌状态
- **WHEN** 批量操作包含符号链接、涉及共享存储、重复点击或 Activity 重建
- **THEN** 操作链接本身且不跟随删除外部内容，共享存储遵循现有授权，写任务串行且不会重复提交，未完成任务不冒充已恢复成功。
