# Native Box64真正多版本并存

## 目标与授权
用户在明确获知内置Box64仍覆盖共享bin/box64、自定义版本已可逐游戏选择后，要求“实现真正的多版本并存”。此指令确认前述独立安装目录、逐游戏版本选择、依赖准备与准确启动路径方案，直接进入已批准实施。

## 范围
内置0.2.7与自编译0.4.4改为独立安装；选择器可保存具体版本；未指定时确定使用0.2.7；保存/准备/启动只使用所选版本，不执行缺失回退。保留自定义版本和PRoot现有隔离，禁止把Native glibc产物当作PRoot运行组件。
不重新编译Box64、不更改远端资产字节、不做旧布局迁移、不添加签名或摘要内容校验、不重建Wine prefix。通过自动依赖准备完成安装，用户无需学习目录。
