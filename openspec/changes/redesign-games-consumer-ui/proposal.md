# Games 消费级 UI 重设计提案

## 背景

现有 Games 主界面沿用后台工具式白底表单：顶部文本 Tab、弱封面、边框卡片和暴露的运行时术语，和竞品调研中盖世游戏 6.x 的内容型启动器体验差距明显。

## 目标

- 将 Games 模块统一为近黑背景、深色分层卡片、青色主操作的独立视觉体系。
- 主界面以游戏封面和“开始/导入”为核心，改为封面网格与底部导航。
- 组件下载和设置保留原能力，但重组为用户可理解的页面层级。
- 详情页先展示封面、可运行状态和启动操作，再渐进披露配置字段。
- 不改变游戏库、组件任务、运行配置和启动链路语义。

## 非目标

- 不复刻竞品品牌、文案、图标或版权素材。
- 不新增网络社区、商店、云游戏、账号和推荐流。
- 不修改 X11、TermuxService、Repository、Orchestrator 或持久任务协议。
- 本分片不全面改造导入、运行配置、启动进度和会话内菜单页面。

## 用户可见行为

进入 Games 后直接看到深色游戏库、运行环境状态、导入入口和两列封面卡片；底部在游戏库、运行组件、设置之间切换并在重建后保持位置。点击游戏进入内容优先详情页，首屏可确认目录状态并启动，技术字段位于高级设置区。

## 影响范围

仅修改 `:games` 的主题、颜色、主 Activity、详情布局、列表项、资源和 UI AndroidTest，以及本 change 的 OpenSpec/Harness 产物。

## 风险与回滚

- 小屏/横屏：使用自适应两列 GridLayout 和可滚动内容，避免固定宽度溢出。
- 封面异步加载：保留 generation 防串图机制，使用 centerCrop。
- 导航回归：BottomNavigationView 继续映射原三个 tab 状态并持久化 selectedTab。
- 回滚仅需恢复 Games 资源和 `LocalGamesActivity`，不涉及用户数据迁移。
