# 资源与脚本直接执行

## MODIFIED Requirements

### Requirement: 不再实施资源内容摘要或签名门禁
App自管下载、缓存、组件安装/收据/预检、RootFS/prefix及Native/PRoot/桌面资源不得因内容摘要或签名不同而拒绝。不得引入校验开关、任务校验策略、未校验标记、收据隔离或补救流程。内置脚本正常释放与更新。

#### Scenario: 内容不同但格式有效
- **WHEN** 资源内容摘要与原描述不同，且传输、格式、路径和架构满足要求
- **THEN** 正常处理，不因摘要不同拒绝、回退或重建。

### Requirement: 保持运行功能约束
保留版本/后端/架构、PE/ELF格式、解压路径/结构及必需文件检查。内部标识字段不作为资源内容门禁。APK系统签名、包管理器信任和备份事务不属于本项自管资源内容校验。

#### Scenario: 格式与路径无效
- **WHEN** 归档路径越界、架构错误、格式无效或必需文件缺失
- **THEN** 明确失败，不能因取消内容摘要而直接接受无效输入。

#### Scenario: 源文件或归档文件长度变化
- **WHEN** Native或PRoot的DLL被替换，或有效归档文件长度不同于模板记录
- **THEN** 直接复制实际内容，不因预期长度或展开字节总数不同拒绝，不启动wineboot或重建。
