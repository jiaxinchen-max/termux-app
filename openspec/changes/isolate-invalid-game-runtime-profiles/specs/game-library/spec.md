# 游戏库

## ADDED Requirements

### Requirement: 无效配置逐游戏隔离
系统必须保留无效配置的游戏记录和错误，不能因此清空其他游戏或阻断新导入。不得为无效配置补默认运行参数或启动。

#### Scenario: 有效与旧配置混合
- 当一个游戏缺少 xinputEnabled 或 dinputEnabled，另一个游戏配置有效
- 则有效游戏正常显示，无效游戏显示配置错误且不能启动，导入入口可用。

#### Scenario: 无法确认后端
- 当配置的绑定元数据亦损坏
- 则在两个集合都提供该记录的错误与删除入口，不猜测运行后端。

### Requirement: 可删除无效配置
系统必须在显式删除前强杀可验证的关联任务，再删除游戏记录和无效配置；不得删除外部文件或凭损坏元数据删除运行目录。

#### Scenario: 删除缺少接口字段的记录
- 当用户确认删除旧配置游戏
- 则先强杀已确认的作用域，再移除卡片、当前配置与成功快照，不迁移数据。

#### Scenario: 强杀失败
- 当强杀操作失败
- 则删除失败，记录与配置仍保留。

#### Scenario: 其他记录的引用未知
- 当删除有效游戏而其他配置无法确认容器绑定
- 则不能将容器判为无引用后清除；其他游戏配置不得导致本游戏记录删除失败。
