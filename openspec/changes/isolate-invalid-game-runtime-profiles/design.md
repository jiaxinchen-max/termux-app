# 设计

列表逐个读取严格 RuntimeProfile；单项 IOException 只写入该游戏错误状态，不终止全库。有错误的卡片明确显示配置无效，禁止启动、桌面及配置编辑，只保留错误详情与删除；正常条目和导入入口不受影响。轮询刷新同时比较错误集合，避免损坏或恢复后保留旧 UI 状态。

新增只读绑定元数据类型，只验证记录 ID、后端、containerId 与 Wine 标识，不包含手柄开关或其他运行参数，也不生成可执行配置。仅用于集合归类、强杀作用域与保守删除引用检查。缺少或损坏这些字段不填默认值。严格 find/list 和启动快照校验保持不变。

强杀使用已验证绑定及按 gameId 关联的任务，包含终态任务；无效配置也不得跳过强杀。绑定未知时只使用已证实的游戏任务范围，不删除未知容器。其他配置的绑定无法判定时，不推定容器已经无人使用。失败时终止该删除，不继续发布移除结果。无效记录的当前配置与成功快照均在显式删除时移除，防止残留再次干扰。

回滚仅恢复本轮源文件；不改磁盘旧配置，不动 Wine/RootFS/prefix 与手柄归档。覆盖两后端、混合有效/无效记录、字段缺失与非法值、未知绑定、删除前强杀及失败原子性。Harness 引导/严格脚本与产品基线缺失将明确记录。
