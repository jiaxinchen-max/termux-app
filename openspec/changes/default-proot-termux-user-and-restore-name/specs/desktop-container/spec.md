# 容器用户及备份名称

## ADDED Requirements

### Requirement: 新容器提供默认普通用户
系统必须在新容器构建时建立 termux 普通用户，设置初始密码 termux，桌面和用户启动的应用必须在普通用户环境运行。所需管理服务和安装任务可以使用容器 root，不得将其身份传给桌面应用。缺少该账户时必须明确失败，不得静默切回 root。

#### Scenario: 新装容器启动 VLC
- 当用户在新容器中通过 Discover 安装并启动 VLC
- 则 VLC 进程使用非零 UID、HOME=/home/termux，能够显示窗口，不触发 root 拒绝。

#### Scenario: 需要安装软件
- 当普通用户通过 Discover 或 sudo 请求管理操作
- 则使用容器内正常授权机制处理，初始账户密码为 termux，桌面应用保持普通用户身份。

### Requirement: 桌面信息显示初始账户提示
容器桌面信息必须显示默认用户 termux 和初始密码 termux，提示可修改密码；Native 信息不得显示该容器提示。不要求迁移旧数据。

### Requirement: 恢复保留名称并去重
导出必须保留用户可见的容器名称。恢复必须保留原名，若最新桌面清单存在同名记录，追加最小可用正整数后缀，显示格式为“原名 (1)”。该规则不得影响新的 ID、容器路径别名、完整性校验或事务清理。

#### Scenario: 名称未占用
- 当备份名称为 工作桌面 且清单没有同名
- 则恢复名称为 工作桌面。

#### Scenario: 名称连续占用
- 当已有 工作桌面 和 工作桌面 (1)
- 则恢复名称为 工作桌面 (2)。

#### Scenario: 后缀有空洞
- 当已有 工作桌面 和 工作桌面 (2)
- 则恢复名称为 工作桌面 (1)。
