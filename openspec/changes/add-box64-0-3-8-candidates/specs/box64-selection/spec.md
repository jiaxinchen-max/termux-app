# Box64版本选择

## 新增需求

### 需求：提供0.3.8双后端候选
Native游戏必须可选择glibc_box64_0.3.8，PRoot的Box64翻译模式必须可选择rootfs_box64_0.3.8。候选仅属于各自后端，版本可独立安装、卸载、重装并与原版本共存。

#### 场景：保存并运行0.3.8
当用户安装并选择对应后端的0.3.8后，保存配置必须保留精确组件ID，启动必须使用该ID的程序及配套库。

#### 场景：维护已安装版本
当用户卸载或重装0.3.8时，仅操作该组件，沿用既有相关任务强停行为，不覆盖其他版本。

#### 场景：未选择或不可用
未显式选择时沿用现有默认版本；选择版本不可用时必须报错，不改成其他版本运行，不自动升级或重建。

#### 场景：交付APK
完成相关本地验证后交付非testOnly的arm64 debug APK，名称固定termux-app_apt-android-7-debug_arm64-v8a.apk，由用户安装测试。
