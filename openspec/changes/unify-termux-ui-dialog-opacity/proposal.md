# 统一 termux-ui 对话框背景

## 需求

用户要求将 `termux-ui` 的弹出对话框背景统一为 85%。延续上轮不透明度的讨论，规划按 **85% 不透明、15% 透明** 实施；Android 8位 alpha 采用最接近的 `0xD9`（217/255）。

当前普通共享对话框约55%／58%不透明、文件管理器90%、USB全不透明，安装／组件／prefix日志窗口又使用单独的不透明控制台背景，造成页面之间不一致。

## 拟议变化

- 亮暗主题的公共对话框背景统一采用85%不透明度。
- 文件管理器、USB及日志对话框接入公共背景，清除独立透明度覆盖。
- 默认内容区域保持透明，使窗口只绘制一层背景；日志终端中程序明确绘制的ANSI色块仍属于内容，不因本次调整被去除。
- 沿用现有亮暗配色、圆角、描边、模糊及遮罩规则；文字和按钮不整体变淡。

API文档为N/A，无HTTP契约变化；产品文档为Required，目标 `docs/product/ui-appearance.md`，验收前一致性Pending。当前仓库没有该产品目录，最终验收后再维护权威文档。

本轮扩大了已实现的文件管理器局部90%范围。须在新规划确认后实施，并同步上轮规划中被替代的视觉条款；上轮文件识别和导入交互仍然有效。未经本轮独立授权不发布Git、不安装设备、不归档。构建继续保持原名普通debug APK。
