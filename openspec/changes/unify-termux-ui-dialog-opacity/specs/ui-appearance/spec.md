# 统一对话框背景

## MODIFIED Requirements

### Requirement: 模块弹出对话框共用85%不透明背景

`termux-ui` 自行绘制的普通及自绘对话框 MUST 使用共同的亮暗主题背景填充，背景不透明度为85%（8位alpha取0xD9）。文件管理器、USB、运行环境／prefix／组件日志对话框及共用弹层底色的浮动菜单 MUST 遵循同一规则，不得各自保留其他百分比。该要求替代上一轮文件管理器局部90%背景要求。

#### Scenario: 亮暗主题与无模糊环境
- **WHEN** 用户在亮色或暗色、支持或不支持系统模糊的环境打开这些对话框
- **THEN** 实际窗口背景采用共同85%不透明填色，原有圆角、描边、文字和操作保持正常，背景不依赖系统模糊才生效。

#### Scenario: 自绘控制台及嵌套内容
- **WHEN** 日志Dialog显示、更新或切换主题
- **THEN** 默认内容区域不以额外不透明或半透明整块填色遮挡／叠加窗口底色，文字不整体变淡，已有输出、会话连接和程序显式ANSI背景保留。

#### Scenario: 界面范围
- **WHEN** 修改本模块的对话框主题
- **THEN** 保持现有选项、确认／取消、导入、文件操作及会话逻辑，全屏终端和其他非对话框区域不被整体改为85%；系统绘制的授权及应用选择器遵循系统主题。
