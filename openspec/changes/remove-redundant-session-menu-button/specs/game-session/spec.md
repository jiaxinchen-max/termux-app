# 游戏会话菜单入口

## MODIFIED Requirements

### Requirement: 游戏画面不显示重复的悬浮菜单按钮
游戏会话界面 MUST 移除底部中央的「☰」按钮，通过系统返回操作打开已有控制抽屉。

#### Scenario: 游戏画面与抽屉反复切换
- **WHEN** 用户进入 Native 或 PRoot 游戏会话，使用返回键或返回手势打开、关闭控制抽屉
- **THEN** 控制抽屉沿用现有行为，游戏画面上始终没有底部中央菜单按钮

#### Scenario: 横竖屏切换
- **WHEN** 游戏会话在横屏与竖屏之间切换
- **THEN** 两种方向均不出现该菜单按钮，返回操作仍可打开控制抽屉

#### Scenario: 抽屉逐级返回
- **WHEN** 用户位于控制器子页、抽屉根页或退出确认状态并触发返回
- **THEN** 沿用现有上级导航、关闭抽屉与退出确认规则
