# 移除游戏会话重复菜单按钮

## 目标与用户可见行为
移除截图中游戏画面底部中央的「☰」悬浮菜单按钮，避免遮挡画面。用户通过系统返回键或返回手势打开控制抽屉；抽屉已打开时继续使用现有逐级返回和关闭行为。Native 与 PRoot、横屏与竖屏统一适用。

## 范围与非目标
仅删除游戏会话布局中的按钮，以及它的点击绑定、打开抽屉时隐藏按钮和关闭抽屉时恢复按钮的代码。若菜单按钮专用无障碍文案无其他引用，一并清理。保留抽屉内容、退出确认、游戏输入、桌面会话与游戏卡片菜单。

## 文档与兼容性
不涉及 HTTP 契约，api_docs 为 N/A。属于用户可见交互调整，product_docs 为 Required，验收后维护 docs/product/game-session.md，当前一致性为 Pending。不涉及数据格式、旧数据迁移或运行时回退。

## 风险与回滚
需要确认返回键和手势仍可打开抽屉，关闭抽屉及旋转屏幕后按钮不会恢复。必要时仅恢复本次删除的布局和引用代码，不覆盖工作区既有修改。

## 确认状态
用户已明确批准执行本方案。
