# 桌面管理

## MODIFIED Requirements

### Requirement: 管理网格固定卡片
系统 SHALL 以 128 × 160dp 显示 Native/PRoot 管理网格的桌面、新增和导入卡片，封面高度 52dp。卡片按窗口宽度换行，不随视口高度或字体增高、增宽；窗口不足一张时仅允许收缩宽度。列表保持全宽。

#### Scenario: 平板视口
- **WHEN** 管理页在较高或较宽视口测量
- **THEN** 三类卡片保持固定尺寸，参数、状态和 48dp 底部操作仍在卡片内。

#### Scenario: 长名称与大字体
- **WHEN** 桌面名称较长或系统字体放大
- **THEN** 卡片保持固定，名称最多两行、正文有限行省略，按钮不被挤出；完整文本可经现有列表和设置查看。

#### Scenario: 原有交互与主题
- **WHEN** 用户切换浅深色或使用启动按钮
- **THEN** 使用现有主题配色、启动确认和点击防重规则，不增加后台初始化。
