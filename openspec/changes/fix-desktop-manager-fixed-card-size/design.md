# 设计

管理页的 item_desktop 封面 FrameLayout 使用 wrap_content，而背景 ImageView 与遮罩为 match_parent。ScrollView 的有限高度测量允许装饰层占满可用高度，继而拉长同排 action 卡片；既有测试只用 UNSPECIFIED 测量单卡，未覆盖截图中的视口约束。

按用户最新要求固定网格卡片宽 128dp、高 160dp、封面高 52dp，以共享 dimen 约束实际 GridLayout 参数和三个卡片根节点。行位置使用顶部对齐，取消 action 卡片按行填充；列数只按固定宽度计算，不再因字体改变卡片宽度。窗口不足一张时仅收缩宽度避免溢出。

卡片内容高度 match_parent；固定封面内角标顶部靠右、名称底部两行省略，避免背景参与固有高度测量。正文使用剩余空间，参数限制行数并省略，状态单行，底部操作行固定 48dp。大字体不扩大卡片；完整名称保留在控件文本和现有设置/列表中。现有主题色、启动确认、防重复点击与光带生命周期不变。

仅修改管理页布局、摆放参数与现有 UI 回归用例；不修改创建页的封面设计或任何桌面后台逻辑。回滚只撤销本变更，保留七个既有脏子模块。规划由“固定宽高”直接确认；不存在已声明的额外受保护路径。复用现有 Robolectric 测量用例增加真实视口约束并更新固定尺寸预期，按钮保留 48dp 触控高度与约 28dp 的可见背景，单行文字按可用区域缩放/省略，避免大字体被上下内边距裁切。布局测量用例使用原生图形模式，避免旧图形替身对不同文字尺寸固定返回 41px 字高。运行管理页/创建页既有回归与 APK 构建。仓库缺少 Harness 脚本和 OpenSpec CLI，不能声称严格门禁通过。
