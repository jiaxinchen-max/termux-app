# 会话视觉

## ADDED Requirements

### Requirement: 嵌入会话的纯色空闲背景
游戏和桌面的 X11SessionView MUST 不显示中央 X 标识及附属装饰，并以随应用主题变化的不透明纯色展示空闲区域。

#### Scenario: 浅色或深色模式下尚无画面
- **WHEN** 用户打开游戏或桌面会话且尚未呈现画面
- **THEN** 空闲区域为当前主题的纯色，无 X 标识或雷达装饰

#### Scenario: 会话呈现真实画面
- **WHEN** X11 已开始输出画面
- **THEN** 正常呈现帧内容，纯色背景不覆盖帧

### Requirement: 游戏等待层不叠加背景色
游戏等待提示 MUST 不在运行画面上叠加全屏半透明背景色。

#### Scenario: 连接或等待首帧
- **WHEN** 游戏显示连接或等待首帧状态
- **THEN** 保留状态提示与进度，等待层背景透明

#### Scenario: 原有交互
- **WHEN** 用户使用菜单、输入或确认退出
- **THEN** 原有交互职责继续有效
