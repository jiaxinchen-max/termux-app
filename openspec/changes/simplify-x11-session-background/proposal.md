# 简化游戏与桌面运行背景

## 目标与用户可见行为
游戏和桌面的小 X11SessionView 空闲时去掉中间 X 标识及其雷达装饰，显示随应用深浅主题变化的不透明纯色背景。游戏运行页去掉全屏半透明等待遮罩，保留连接、等待首帧和停止过程的文字与进度提示。

## 范围与非目标
修改共用 UI 空闲布局、嵌入会话背景和游戏等待层背景。终端模式 X11 空闲展示、真实 X11 帧内容、任务状态、抽屉操作、退出确认与输入交互保持原有职责。不增加旧数据迁移。

## 文档分类
api_docs 为 N/A：无 HTTP 契约变化。product_docs 为 Required：验收后更新 docs/product/desktops.md 与 docs/product/games.md；当前文件缺失，待创建，状态 Pending。

## 风险、兼容性与回滚
移除装饰控件后需确认共用运行时的雷达查找允许为空；背景不能覆盖真实帧。最低 Android 21 兼容要求不变。回滚限于本次布局、主题资源及背景设置改动，不回滚其他桌面启动优化。
