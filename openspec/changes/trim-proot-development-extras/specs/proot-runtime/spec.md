# PRoot 运行镜像裁剪

## ADDED Requirements

### Requirement: 低风险文件定向清理

离线裁剪工具 SHALL 仅删除 Perl 开发头文件、纯 POD 文档及非中文／英文 gettext 翻译普通文件，并同时删除同语言 LC_TIME 中指向该已选同名翻译的 .mo 链接；保留法律声明、受保护文件及所有其他存活链接依赖。

#### Scenario: 裁剪当前预装镜像

- **WHEN** 维护者提供当前镜像及对应描述生成独立候选
- **THEN** 工具输出删除明细及实测体积，其余文件的内容、权限、链接和所有清单守卫保持不变
- **AND** Perl 运行模块、LLVM／Gallium、中文字体与 locale、Wine NLS、两种 PE 架构和 FEX／Box 均保留

### Requirement: 失败终止与独立交付

离线工具 SHALL 核对完整输入及输出，任何损坏、保护冲突或归档异常立即失败；不得修改输入、覆盖已有候选或自行改写线上版本及客户端配置。发布和客户端接入仅在用户明确授权后实施。

#### Scenario: 输入损坏或输出失败

- **WHEN** 任一成员与清单不一致或压缩／复读失败
- **THEN** 终止操作且不留下可交付候选，不通过重建或其他回退掩盖错误

#### Scenario: 静态验证成功

- **WHEN** 候选包及恢复后的全部保留文件核对通过
- **THEN** 仅报告离线制品验证通过，将真实运行验收标为待完成，保留历史裁剪记录而不伪造新的运行验证状态

### Requirement: 授权后替换原资产并交付 APK

系统维护者 SHALL 在用户批准后替换原仓库原标签的同名镜像，保持组件身份及版本，更新 APK 内镜像描述及索引，提供原名、原签名、非 testOnly 的 arm64-v8a debug APK。

#### Scenario: 用户要求直接发布并手动安装验证

- **WHEN** 用户明确授权“直接发布后替换，我下载apk进行验证”
- **THEN** 维护者完成镜像发布、公开下载核对、APK 构建及嵌入资产核对后交付下载链接
- **AND** 不自动升级已有环境、不更改校验策略、不执行设备安装，实际运行验收保持待用户完成

### Requirement: 显式构建必须准备当前基础镜像

用户主动确认 Build from network 时，系统 SHALL 使用当前 APK 索引创建新的基础镜像安装任务，再恢复 RootFS；不得直接复用旧 active 记录或历史失败任务。常规程序依赖准备 SHALL 保持复用已安装组件，不基于版本或摘要自动升级。

#### Scenario: 更新 APK 后仍装有旧镜像包

- **WHEN** 旧镜像组件版本号相同且用户主动点击 Build from network
- **THEN** 当前镜像的安装任务完成后才开始恢复，旧安装目录不得造成提前跳过准备
- **AND** 可复用满足现有下载规则的外部缓存，失败立即终止，不回退旧包或源码重建

#### Scenario: 普通程序初始化

- **WHEN** 程序准备依赖且组件 active 目录已存在
- **THEN** 不因索引变化重装该组件
