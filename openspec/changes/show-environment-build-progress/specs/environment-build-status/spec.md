# 环境构建状态

## ADDED Requirements

### Requirement: 构建活动持续可见
系统 MUST 在Native与PRoot环境构建期间显示该环境的活动状态，且不阻断点击操作。

#### Scenario: 构建正在执行
- **WHEN** 对应环境存在排队、安装或重建清理任务
- **THEN** 设置详情页与核心组件摘要显示对应活动状态，Build行显示执行中提示和小型进度指示，保持可点击

#### Scenario: 用户查看或关闭日志
- **WHEN** 用户点击执行中的Build入口
- **THEN** 打开已有任务日志，不创建重复任务；关闭日志后提示仍存在，其他安全操作和页面导航可用

#### Scenario: 页面恢复
- **WHEN** 用户离开再返回或Activity重建
- **THEN** 从真实任务状态恢复提示，不以界面临时变量判定正在构建

### Requirement: 终态准确刷新
系统 MUST 在任务成功或失败后显示准确结果，不将失败当成成功。

#### Scenario: 构建成功
- **WHEN** 任务成功结束
- **THEN** 移除执行中指示，重新读取实际环境就绪状态并恢复常规Build说明

#### Scenario: 构建失败
- **WHEN** 任务失败
- **THEN** 显示失败与查看详情入口，按原规则允许用户重试，不自动回退或重建
