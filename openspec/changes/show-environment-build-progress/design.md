# 设计

## 界面行为
在设置的Native/PRoot详情页，构建活动期间Status显示“构建中”，Build from network副文案显示“任务执行中，点击查看进度”，附小型不确定进度指示。核心组件上级页对应后端摘要同步显示执行中。排队可显示“等待执行”，重建清理阶段显示“正在准备重建”。不增加全屏遮罩，不禁用Build行或页面导航；用户主动点击才打开已有任务的日志，关闭日志后状态提示继续存在。

任务成功后重新读取环境就绪状态，并恢复正常构建说明。任务失败显示“构建失败，点击查看详情”，不能仅因任务结束而显示成功或隐藏错误；用户仍可按现有规则重试。未知进度不制造百分比。

## 状态来源与刷新
LocalGamesActivity当前renderRuntimeStatus只读取环境文件就绪状态，不能表达运行任务。新增只读任务投影，按Native/PRoot区分组件安装、基础RootFS任务与对应ResetTarget；PRoot下载安装阶段也纳入。状态读取在工作线程，UI只应用快照。页面可见时周期刷新，离开/停止时取消，返回时立即读取；任务结束执行最终刷新。避免反复重建菜单抢走点击、滚动位置或现有对话框。

复用现有日志入口与服务层互斥；只读状态不创建任务。点击进行中的同后端构建进入已有任务日志，其他操作沿用现有并发保护。不开新回退路径，不改变前后台任务生命周期。

## 影响与回滚
涉及设置菜单行、LocalGamesActivity任务状态投影及刷新、本地化文案和针对性测试；不变更网络契约、持久化格式和安装脚本。回滚撤销本次UI与投影，无数据迁移。仓库Harness引导及严格校验脚本、OpenSpec CLI缺失，记录Unavailable，使用本地测试和代码审查，不声称严格门禁通过。
