# Proton 字体支持

## 新增需求：预构建模板提供有效中文字体链
Proton 模板必须使系统界面和游戏请求的常用字体可解析到真实存在的字体，并为中文缺字提供现有 Noto CJK 字体。字体注册不得依赖构建机或未挂载的 PRoot 绝对路径。

### 场景：请求缺少的 Segoe UI
当请求 Segoe UI 或 Segoe UI Semibold 且包内没有原字体时，模板映射到已有中文无衬线字体，不得仅映射到无中文字形的 Times New Roman。

### 场景：拉丁字体缺少中文
当现有 Verdana、Arial 或 Times New Roman 的拉丁字形可用但中文缺字时，保留有效字体并通过相应中文链接提供缺字；字体类型和排版需人工验收。

### 场景：使用新模板
新导入 Proton 游戏从外部资产或缓存恢复独立 prefix，启动不执行 wineboot、重建或运行时字体修补；失败明确终止，不改用其他 Wine。

### 场景：保持 Wine 9.3 正常
本变更不更改已验证 Wine 9.3 的模板和字体配置，也不增加 APK 内压缩 prefix 负载。历史 prefix 不自动迁移。
