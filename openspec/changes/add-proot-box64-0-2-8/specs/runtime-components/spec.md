# PRoot Box64 0.2.8候选

## 新增需求：独立候选
PRoot的Box64列表必须可选rootfs_box64_0.2.8，允许独立安装、卸载、重装，按游戏保存与回读准确ID。PRoot默认0.4.5以及现有0.3.8与Native候选不变。

### 场景：选择0.2.8
游戏与维护任务必须使用/opt/box64/rootfs_box64_0.2.8/bin/box64及同目录对应的lib/x86_64-linux-gnu，不能使用Native加载路径或默认版本库。

### 场景：缺少组件
显式选择的0.2.8缺失时必须失败，不能换版或重建环境。

## 新增需求：构建交付
原资产仓库的rootfs_box64_0.2.8包必须使用固定源码、PRoot解释器及必要x86_64库，正常APK使用既有文件名且testOnly=false，设备游戏验证由用户手动完成。
