# 规范Box64资产文件名

## 需求与范围
用户明确要求规范文件命名。当前Native/glibc 0.4.4使用名称含proot的历史资产，Native 0.2.7使用不含后端与程序版本的通用文件名，容易误判适用环境。统一当前Box64资产的文件名为组件ID加.tar.xz；PRoot已有规范文件名保持。

|组件ID|当前文件名|规范文件名|
|---|---|---|
|glibc_box64_0.2.7|box64-binaries.tar.xz|glibc_box64_0.2.7.tar.xz|
|glibc_box64_0.4.4|box64-proot-v0.4.4.tar.xz|glibc_box64_0.4.4.tar.xz|
|rootfs_box64_0.4.5|rootfs_box64_0.4.5.tar.xz|rootfs_box64_0.4.5.tar.xz|

用户的命名指令确认本次范围；只修改分发元数据、当前打包输出示例及发布名称，不修改业务代码、组件身份、程序版本、索引修订、包内容或运行路径，不引入自动升级。将两个Native原包以规范名称发布到原资产仓库的同名组件标签，当前索引改用规范地址。原输入资产作为构建来源保留，不实现旧地址回退逻辑。
